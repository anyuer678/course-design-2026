# B5-cpu-sim —— 单周期 CPU + 五级流水线（数字设计与计算机原理 / 计组）

**课程映射**：数字设计与计算机原理（PLAN 批次 2）。

一句话：**CPU 的"对"有两层**——单周期把 ISA 语义做对，流水线还要把**冒险**处理对；
而流水线是否可信，看的不是"跑得快"，是**最终寄存器与内存和单周期逐字节相同**。

**红线（先说在前）**：这是**教学模型**，不是可综合的 RTL：指令集是 MIPS 子集、
用结构体代替位域、没有时钟树/握手/存储层次；访存是理想单周期。`halt` 是本实现的教学约定
（独占一个 opcode）。**不冒充**真实处理器的时序与面积。

## 运行

```
run.bat                                              # 三步：自测 → 双模型演示 → 时空图
g++ -std=c++17 -O2 -Wall -Wextra -static -Iinclude tests\test_cpu.cpp -o build\tests.exe && build\tests.exe
g++ -std=c++17 -O2 -Wall -Wextra -static -Iinclude src\main.cpp -o build\cpu-sim.exe
build\cpu-sim.exe programs\bubble.asm                # 冒泡排序：单周期 vs 流水线
build\cpu-sim.exe --chart programs\bubble.asm        # 流水线时空图（S=停顿，F=冲刷）
build\cpu-sim.exe --chart programs\loop.asm          # 最小循环：看分支冲刷
```

只用 g++ 与标准库，**零下载零安装**。

## 知识点 ↔ 实现 ↔ 怎么被验证

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
| 指令编码与 r0 恒零 | `isa.hpp` `encode` / `RegFile` | 写 r0 被丢弃、读 r0 恒 0（两条断言）；R/I/J 三型各自编码路径 |
| 汇编器两遍扫描 | `asm.hpp` `assemble` | 前向跳转标签能解析成绝对地址；未定义标签必须报错；同行标签+注释 |
| 单周期语义 | `cpu.hpp` | 22 项 ISA 断言：算术/逻辑/移位/访存往返/负立即数/有符号 slt/分支跳/不跳/j/halt |
| 访存越界 | `DataMem` | 越界 **抛错**（不是读到垃圾） |
| 周期数与控制流 | `cpu.hpp` | 直线程序周期数 == 指令数；trace 里能看到 pc 从 0 跳到 2 |
| 数据冒险：前递 | `pipeline.hpp` `forward` | 相邻 add→add **零停顿**且值正确（EX/MEM 与 MEM/WB 两级） |
| 数据冒险：load-use | 停顿检测 | 相邻 lw→add **恰好停顿 1 周期**且读到正确值 |
| 控制冒险：冲刷 | EX 判定 + flush | 分支跳了 → 冲刷 ≥1 次；没跳 → **0 次** |
| **双模型对拍**（核心验收） | `SingleCycleCpu` vs `PipelineCpu` | 混合程序与**冒泡排序**上：寄存器逐一相同、内存逐一相同 |

## 实测（2026-10-02，事故后按幸存 `run.bat` 与 PLAN 记录重建）

- 自测：**42 项断言，0 项失败**（原记录是 39 项；重建的实现与测试不是逐字同一份，数字如实更新）。
- `run.bat` 连跑两次退出码 **0**、`not recognized` **0**、目录**无新增文件**（`build/` 之外），
  两次日志**逐字相同**（`diff` 0 行）。
- 双模型读数（现算）：冒泡排序（输入 `5 1 4 2 3`）单周期 **159 周期**、流水线 **219 周期**
  （停顿 10、冲刷 23；`--chart` 里数组未预置时冲刷 29、分支 29 跳 15），排序结果 `1 2 3 4 5`，
  **两模型寄存器完全一致**。

## 重建时踩到的坑（2026-10-02；都是先跑出错误再修的）

1. **取到 `halt` 之后还要继续取指** → 越界报错。修法：见到 halt 就**冻结取指**，只等流水线排空。
2. **分支跳转时"取了目标又把它冲掉"，而 pc 已前进** → 目标指令被跳过、循环变死循环。
   修法：跳转周期 IF 只发气泡、不取指，下周期从目标取。
3. **`pc_frozen` 冲刷后不清** → 跳转前恰好取到过 halt，排空后永不再取指（假死）。
   修法：跳转时清冻结标志。
4. **`is_load` 标志设得太晚**（EX 阶段才置）→ load-use 检测完全失灵（结果读到旧值）。
   修法：进入 EX 时就带上 `is_load` 与 `dest`。
5. **`sll/srl` 的源是 rt 不是 rs**（`sll rd, rt, shamt`）→ 用 rs 的转发值算出恒 0；
   是**双模型对拍**抓出来的（单周期一直是对的）。
6. **`run()` 整个重建 Machine** → 调用方预置的内存/寄存器被清空；改成只重置控制状态。
7. **汇编器在分派前做"必须有操作数"的全局检查** → `halt` 被误伤（它本来就没操作数）。
8. 工具面：heredoc 里写 `\n` 会被吃掉（C++ 字符串被拆行）——**改文件用 Edit 工具，别用 heredoc 拼**。
