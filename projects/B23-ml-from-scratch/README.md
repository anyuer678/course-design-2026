## 实现时踩到的坑（先跑出失败再修的）

1. **决策树"零增益即停"学不会 XOR**：XOR 在根节点任何单次分裂的
   信息增益恒为 0（两个子节点都还是 1:1），第一版实现精度 0.5。
   修正为"节点不纯就允许分裂（含零增益）"，max_depth/min_samples 兜底。
   教训：贪心 + 局部零增益 ≠ 全局无信息，XOR 是标准反例。
2. **sign(0) 的归属是实现的一部分**：更新条件用严格间隔
   `y·(w·x+b) > 0`（Novikoff 证明的约定，score=0 也算错），
   手算轨迹若按"score=0 对负类算对"来推就会与实现差 3 轮——
   第一版测试就是这么错的，重推后 4 轮收敛于 w=(2), b=−1。
3. **make_moons/make_blobs 的标签是 0/1**，感知机要求 ±1——
   忘了转换直接 ValueError，两处测试同错。
4. **特征尺度拖垮梯度下降**：Iris 原始量纲下 GD 8000 轮与闭式解差
   1e-3 量级；标准化后 1e-12 收敛。标准化不只是防泄漏的卫生习惯。
5. **KNN k=3 会被多数类淹没**：查询点最近邻是 B，但 3 邻居里 2:1
   是 A——"k=1 跟最近邻、k 大随多数"的天然行为，测试已钉成教学实例。
6. **阈值必须实测钉值**：moons BP 第一版断言 ≥0.95，实测 0.935
   （hidden=8/400 轮欠拟合）；换 16/800 后实测 1.00，阈值钉 0.98 留余量。
   noise=0.15 下两月牙本身有重叠，测不满不代表没训好。

## 测试策略（33 项）

- **数据**：形状/均衡/取值范围/公开均值锚点；切分互斥完备可复现；
  泄漏检查（训练集统计量、离群点保持离群）
- **线性回归**：三点精确拟合、闭式解 vs GD（< 1e-6）、解析梯度 vs
  数值梯度（< 1e-6）、方程组求解、R² 三态
- **感知机**：手算轨迹逐数断言、AND 门、blobs 收敛、XOR ≤ 75%
- **KNN**：kneighbors vs 独立排序参照、手算投票、平局确定性
- **决策树**：根分裂 vs 独立增益穷举、可分数据 100%、XOR 对照
  （depth=5 全对 / depth=1 必不满分）、确定性、概率和为 1
- **BP**：数值梯度检查（抽查 25+ 参数，< 1e-5，实测 2.6e-9）、
  损失下降、XOR 100%、月牙 ≥ 0.98、概率和为 1
- **Iris 端到端**：KNN/树/BP ≥ 0.9、感知机二分类 ≥ 0.9、线性回归 R² ≥ 0.75
  （全部固定种子实测阈值，README 注明非理论界）

## 已知局限

- 纯 Python 实现，训练规模控制在千级样本、网络 ≤ 几百参数。
- KNN 预测 O(n·d) 暴力扫描；无 KD-tree。
- 决策树只支持连续特征的二叉分裂；无剪枝（靠深度限制）。
- BP 只支持全连接 + tanh/ReLU；无正则化、无优化器（只有 SGD）、
  无学习率调度。
- 精度阈值是单一种子实测，不是统计显著意义上的性能结论。

## 练习建议

1. 实现 k-fold 交叉验证，报告 KNN 的均值±标准差，体会"单一切分的偶然性"。
2. 给 BP 加 L2 正则与早停（patience），观察过拟合曲线（用带噪声的月牙）。
3. 实现逻辑回归（sigmoid + 交叉熵），并与感知机在同一线性可分数据上
   对比决策边界（概率输出 vs 硬判别）。
4. 把决策树的准则换成"增益率"（C4.5），解释它为何偏向少取值的特征。
5. 证明：两层线性网络（无激活）等价于一层线性——用代码验证 W2W1 的
   参数化并数一数有效参数量。
