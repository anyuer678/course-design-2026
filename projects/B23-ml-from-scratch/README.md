## 实现时踩到的坑（先跑出失败再修的）

1. **决策树"零增益即停"学不会 XOR**：XOR 在根节点任何单次分裂的信息增益恒为 0
   （两个子节点都还是 1:1），第一版实现精度 0.5。修正为"节点不纯就允许分裂（含零增益）"，
   max_depth/min_samples 兜底。教训：贪心 + 局部零增益 ≠ 全局无信息，XOR 是标准反例。
2. **sign(0) 的归属是实现的一部分**：更新条件用严格间隔 `y·(w·x+b) > 0`
   （Novikoff 证明的约定，score=0 也算错），手算轨迹若按"score=0 对负类算对"来推
   就会与实现差 3 轮——第一版测试就是这么错的，重推后 4 轮收敛于 w=(2), b=-1。
3. **make_moons/make_blobs 的标签是 0/1**，感知机要求 ±1——忘了转换直接 ValueError，
   两处测试同错。
4. **特征尺度拖垮梯度下降**：Iris 原始量纲下 GD 8000 轮与闭式解差 1e-3 量级；
   标准化后 1e-12 收敛。标准化不只是防泄漏的卫生习惯。
5. **KNN k=3 会被多数类淹没**：查询点最近邻是 B，但 3 邻居里 2:1 是 A——
   "k=1 跟最近邻、k 大随多数"的天然行为，测试已钉成教学实例。
6. **阈值必须实测钉值**：moons BP 第一版断言 ≥0.95，实测 0.935（hidden=8/400 轮欠拟合）；
   换 16/800 后实测 1.00，阈值钉 0.98 留余量。noise=0.15 下两月牙本身有重叠，
   测不满不代表没训好。
7. **（候选⑤）sklearn 的默认早停会截胡**：`MLPClassifier` 默认 `n_iter_no_change=10`，
   300/1000/3000 轮结果**一模一样**且卡在 loss≈0.351（它第 ~10 轮就停了）。对拍参数必须
   `tol=0.0` + 极大 `n_iter_no_change` 把轮数真正打通——不写死这条就会得到"sklearn 学不动"
   的假结论（第一版探针就是这么被骗的）。
8. **（候选⑤）负面对照的"坏参"要用实测选出来**：第一版负面对照用"单隐元 MLP"，
   结果被自己的对拍台**放行**（单隐元 lr=0.1 在 iris 上能到 0.933）——0.267 那个读数的
   真相是探针撞上了默认 lr=0.001。改成"单隐元 + lr=0.001"后可靠必红。
   **"故意写错"必须真的错**，这也是负面对照自己的负面对照。
9. **（候选⑤）RSS 差值口径在小对象上恒为 0**：模型只有千级节点/几百 KB，WorkingSet
   前后差读不出信息量。改 tracemalloc 峰值口径（我们侧=全量；sklearn=下界）并如实声明非对称。
10. **（候选⑤）时间盒要主动收敛并登记**：初版对拍段 ~60 s（全网格内存探测 33.6 s +
    计时/内存各跑一遍的重复训练）；融合测量与网格收敛后 ~40 s。**超出的 8 s 不再裁剪**
    （裁剪=破坏同参），登记在案。
11. **（候选⑤）GBK 扫净又一次、这次是重灾区**：推导笔记用了整套数学记号
    （转置、下标、y_hat 的帽子、偏导、梯度算子、平方上标、减号、上标括号、组合波浪号
    等 **20 种、180+ 处** 非 GBK 字符）。按"保读性"方案替换（`^T`、`_i`、`y_hat`、`d`、
    `grad`、`^2`、`-`、`^(l)`、`_tilde`），并在文档顶部加一行记号兼容说明——
    **符号是可读性资产，替换方案要写清楚而不是悄悄抹掉**。

## 测试策略（54 项 = 核心 33 + 对拍 12 + 展示 9；54 项双入口同数）

- **数据**：形状/均衡/取值范围/公开均值锚点；切分互斥完备可复现；

- **线性回归**：三点精确拟合、闭式解 vs GD（< 1e-6）、解析梯度 vs
  数值梯度（< 1e-6）、方程组求解、R^2 三态
- **感知机**：手算轨迹逐数断言、AND 门、blobs 收敛、XOR ≤ 75%

- **决策树**：根分裂 vs 独立增益穷举、可分数据 100%、XOR 对照
  （depth=5 全对 / depth=1 必不满分）、确定性、概率和为 1
- **BP**：数值梯度检查（抽查 25+ 参数，< 1e-5，实测 2.6e-9）、

  （全部固定种子实测阈值，README 注明非理论界）

## 已知局限

- **对拍只对"单点同参"**：不是超参搜索，也不声称统计意义上的等价；容差是固定种子的实测值 + 余量。
- **sklearn 行为钉在 1.9.1**：版本差异（默认参、内部洗牌）会制造假分歧——规格里所有
  random_state 显式写死，但换版本后读数可能移动（先跑对拍台看红不红）。
- **内存对照是非对称口径**（numpy 的 C 缓冲不在 tracemalloc 内，sklearn 侧是下界）；
  时间数字只展示不做断言（防 flaky），只读量级。
- 纯 Python 实现，训练规模控制在千级样本、网络 ≤ 几百参数（BP 在 n=1000/60 轮已要 2.7 s）。
- KNN 预测 O(n·d) 暴力扫描；无 KD-tree。决策树只支持连续特征的二叉分裂；无剪枝（靠深度限制）。
- BP 只支持全连接 + tanh/ReLU；无正则化、无优化器（只有 SGD）、无学习率调度。

## 练习建议

1. 实现 k-fold 交叉验证，报告 KNN 的均值±标准差，体会"单一切分的偶然性"。
2. 给 BP 加 L2 正则与早停（patience），观察过拟合曲线（用带噪声的月牙）；顺带把
   早停的 patience 也写进对拍参数（想想为什么 sklearn 侧"关掉早停"是必须的）。
3. 实现逻辑回归（sigmoid + 交叉熵），并与感知机在同一线性可分数据上对比决策边界；
   然后加进对拍台与 `sklearn.linear_model.LogisticRegression` 同参对照，先写容差再实现。
4. 把决策树的准则换成"增益率"（C4.5），解释它为何偏向少取值的特征。
5. 证明：两层线性网络（无激活）等价于一层线性——用代码验证 W2W1 的参数化并数一数有效参数量。
