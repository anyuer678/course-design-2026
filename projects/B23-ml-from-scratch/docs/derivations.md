# B23 推导笔记 —— 每个更新规则都从损失函数推出来

> 原则（PLAN §6）：断言的期望值必须有出处。本笔记就是那些出处的推导过程。
> 记号：样本 (x, y)，模型参数 θ，样本数 n，损失 L(θ)。
> 记号兼容说明：为在 GBK 控制台/编辑器下也能读，本文用 `d` 写偏导号、`grad` 写梯度算子、
> `^T` 写转置、`_i/_j` 写下标、`^2` 写平方；公式含义不变。

## 1. 线性回归

模型 `y_hat = w·x + b`。为统一处理截距，给 x 末尾补一个恒 1 的分量，
记增广参数 θ = (w, b)，增广特征 x_tilde = (x, 1)，则 y_hat = θ·x_tilde。

**损失**（均方误差）：

    L(θ) = (1/n) Σ_i (y_i - θ·x_tilde_i)^2

**梯度**：对 θ_j 求偏导（链式法则，内层线性）：

    dL/dθ_j = (1/n) Σ_i 2(y_i - θ·x_tilde_i)·(-x_tilde_ij) = -(2/n) Σ_i (y_i - y_hat_i)·x_tilde_ij

代码里 `mse_gradient` 的 `grads[j] -= err * xj` 再整体乘 `2/n` 就是这一行。
测试用中心差分 `(L(θ+εe_j) - L(θ-εe_j)) / 2ε` 逐分量验证，相对误差 < 1e-6。

**正规方程**：令 gradL = 0。写成矩阵形式（X 的第 i 行是 x_tilde_i，y 是列向量）：

    gradL = -(2/n) X^T(y - Xθ) = 0   ==>   X^TX θ = X^Ty

X^TX 对称半正定；本实现加 1e-10 的对角扰动（等价于极小岭回归）消除奇异，
再用**高斯消元（部分主元）**解方程组——扰动只影响零空间方向，不改变可解部分的解。
**测试对拍**：闭式解与梯度下降（标准化后 8000 轮）差 < 1e-6；
三点精确拟合 y=2x+1 时残差为 0、解精确等于 (2, 1)。

**R^2 = 1 - SS_res/SS_tot**：分母是"拿均值瞎猜"的平方误差，
所以 R^2=0 等价于"不比均值好"，负数等于比均值还差。

## 2. 感知机

模型 `f(x) = sign(w·x + b)`，**约定 sign(0) = -1**（0 的归属是实现的一部分，
不写清就无法对拍——本实现的更新条件随之采用严格间隔形式）。

**损失**（0-1 损失不可导，感知机优化的是它的代理）：

    L(w, b) = -Σ_{i: 错分} y_i·(w·x_i + b)

只对错分样本求和。对某个错分样本求梯度：dL/dw = -y_i·x_i，dL/db = -y_i。
梯度下降一步（学习率 η）恰好给出**感知机学习规则**：

    w ← w + η·y_i·x_i,   b ← b + η·y_i

**收敛定理（Novikoff）**：若存在单位向量 w* 与间隔 γ > 0 使所有样本满足
y_i(w*·x_i) ≥ γ，则更新次数至多 (R/γ)^2，其中 R = max‖x_i‖。
推论：**可分数据有限步收敛；不可分数据永不停止**——所以实现必须有
`max_epochs`，而"跑满轮数没到 100%"正是我们用来**判定不可分**的探测器
（测试里月牙数据就是这么用的）。

**实现约定**（测试的手算轨迹按此推演）：错分判据是 `y_i·(w·x_i+b) ≤ 0`，
即要求**严格**正间隔；score 恰为 0 一律算错。两点数据集 (0,-1), (1,+1) 在
此约定下 4 轮收敛于 w=(2), b=-1，共 5 次更新——逐轮推演写在
`test_hand_traced_trajectory` 的 docstring 里。

## 3. 决策树

**熵**：H(Y) = -Σ_c p_c·log_2(p_c)，p_c 为类 c 的占比。
**条件熵 / 信息增益**：按特征取值分桶后，

    Gain(A) = H(Y) - Σ_v (|Y_v|/|Y|)·H(Y_v)

增益 = "知道 A 之后不确定度减少多少"。本实现用连续特征，候选阈值取
相邻值的中点；**平局取 (特征下标, 阈值) 字典序最小者**——没有这条约定，
同一份数据两次训练可能长出两棵树。基尼不纯度 G = 1 - Σp_c^2 是熵的一阶
泰勒近似，代码两种都实现了。

**XOR 悖论（本轮踩到的最深的坑）**：对 XOR 数据（4 个点，两类各 2），
按 x_1 或 x_2 的任何一次分裂，两个子节点各自仍是 1:1 混合——

    Gain = 1.0 - (0.5·1 + 0.5·1) = 0

**根节点增益恒为 0**，但分裂之后再分裂一次增益就是 1。"零增益即停"的
贪心树因此在 XOR 上永远学不会（第一版实现正是这么错的，精度 0.5）。
修法：只要节点不纯就允许继续分裂（哪怕增益为 0），用 max_depth /
min_samples 兜底防过拟合。教训：**贪心 + 局部零增益 ≠ 全局无信息**，
XOR 是这个结论的标准反例，写进了测试。

## 4. BP 网络（softmax 输出 + 交叉熵）

**前向**：z^(l) = W^(l)a^(l-1) + b^(l)；隐藏层 a = tanh(z)（或 ReLU）；
输出层 softmax：p_j = e^{z_j} / Σ_k e^{z_k}（实现里先减 max 防 exp 上溢）。

**损失**（对 one-hot 目标 t 的平均交叉熵）：

    L = -(1/n) Σ_i Σ_j t_i_j·log(p_i_j)

**为什么 softmax + 交叉熵的梯度恰好是 (p - t)**：
把 z 代入展开，dL/dz_j = p_j - t_j（softmax 的指数与 log 相消，
推导见任何教材；代码注释引用这里）。这就是"softmax 和交叉熵天生一对"，
换 MSE 反而梯度含 p_j(1-p_j) 因子，输出饱和时训练极慢。

**反向传播 = 链式法则的动态规划**。定义误差信号 δ^(l)_j = dL/dz_j^(l)：

    输出层： δ^(L) = p - t
    隐藏层： δ^(l)_i = ( Σ_j W^(l)_j_i·δ^(l+1)_j ) · a^(l)_i·(1 - a^(l)_i)     （tanh）
                          （ReLU 则乘 1[z>0]）
    参数梯度： dL/dW^(l)_j_i = δ^(l+1)_j · a^(l)_i，  dL/db^(l)_j = δ^(l+1)_j

每层只需下一层的 delta 和本层的激活——这就是"反传"省计算的原因
（等价于对整张计算图做一次反向累加，而不是对每个参数独立求导）。

**数值梯度检查**：中心差分

    dL/dθ ≈ (L(θ+εe) - L(θ-εe)) / (2ε)，ε = 1e-6

截断误差 O(ε^2) ≈ 1e-12 量级，与解析梯度相对误差应在 1e-6 以下
（实测最大 2.6e-9）。**手写反向传播的第一道验收就是它**——反传的
索引错位、缺除以 n、激活导数写错，都会被这一检查当场抓住。

**两个工程必须点**：
- 全零初始化会让同层所有单元梯度相同、永远保持一致——必须随机化；
  Xavier 尺度 1/√fan_in 防止 tanh 初始饱和。
- 交叉熵里的 log(p) 加 1e-12 防 log(0)。

## 5. 三值逻辑与数据划分（与 sqlite 对拍同源的严谨性）

- 与 NULL 比较得 UNKNOWN（不是 FALSE）；`IS [NOT] NULL` 是独立谓词。
- AND：有 FALSE 即 FALSE；OR：有 TRUE 即 TRUE；否则含 UNKNOWN 得 UNKNOWN。
  WHERE 只保留 TRUE 的行——这就是"age > 0"选不出 age 为 NULL 的行的原因。

- **数据泄漏**：标准化的均值/方差只能来自训练集。用全量算统计量，
  等于让测试集信息提前参与了预处理——模型评估会系统性偏乐观。
  测试里断言"训练集标准化后均值恰为 0、测试集离群点仍然离群"。
