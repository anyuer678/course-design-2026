岗位（示例）：后端开发实习生（工业软件方向）
职责：
- 参与工业物联网数据采集与后端服务的开发与维护
- 编写并维护单元测试，参与代码评审与质量改进
- 参与数据库表设计与 SQL 查询优化

要求：
- 熟悉 Python 或 Java，了解常用数据结构与算法
- 了解 TCP/HTTP 等网络协议，有 socket 编程经验者优先
- 了解 SQL 与至少一种数据库（MySQL/PostgreSQL/SQLite）
- 有 Linux 系统编程基础（进程、管道）者优先
- 对分布式系统（一致性、共识）有好奇心

加分项：
- 了解前端 HTML/JavaScript 与可视化
- 有 Spark/Hadoop 等大数据工具经验
- 了解安全基础（注入、XSS）
- 了解 Docker/Kubernetes 等容器化技术
- 了解 Kafka 等消息队列
