  2) 五个业务问题：两路算，逐数对拍
==============================================================================
  成交总额                        SQL 765,880 ｜ 参照 765,880  ← 两路一致
      口径：只计 status=DONE；金额=Σ(单价×数量)；按**完成月**归集；退货单（负额）已在清洗链剔除 → 这是不含退货的成交额；品类筛选作用于明细行
  月度成交额与环比                    7 个完成月，未完整月 1 个  ← 两路一致
      口径：横轴是**完成月**；环比=(本月-上月)/上月×100，首月与上月为 0 记 None；晚于最晚下单月（2026-09）的月份是跨月尾巴，标 incomplete 不参与趋势解读
  TOP5 商品与集中度                 冠军 显示器 ｜ CR5 94.0%  ← 两路一致
      口径：排名按**金额**，并列按名称升序（保证可复现）；CR5=TOP5 金额÷总金额；同时给按件数的 TOP5 作对照——两种口径的冠军可以不是同一个商品
  复购率                         41.7%（204/489 客户）  ← 两路一致
      口径：分母=窗口内至少成交 1 单的客户，分子=成交 ≥2 单的客户；窗口按完成月；同一单买两件不同商品**不算**复购（按订单去重）；品类筛选作用于订单（该单出现过该品类即入选）
  履约时长                        P50 5 ／ P90 9 ／ 均值 6.12 天（n=777）  ← 两路一致
      口径：完成日-下单日的整数天；只统计 DONE 单；分位数取 `lead[min(n-1, int((n-1)*q))]`（两路同一公式）；均值被长尾拉动，所以均值/中位/P90 三个都给
  数据质量账本                      账本 1797 行，五步计数全对上  ← 两路一致
      口径：缺陷按声明数量注入，清洗由 B26 的 mining.clean 执行；账本每个计数必须与注入计数逐数对上；本指标描述数据本身，不受筛选影响
  对拍异常清单                      无
