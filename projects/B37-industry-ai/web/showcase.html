怎么自己跑

  • run.bat：三步（测试 → demo（生成 build\ 下 3 张 SVG）→ 展示页新鲜度）。
  • python demo.py：六段演示；python tools\logdiff.py a.log b.log：两次日志规范化比对。
  • python tools\showcase.py --write：重新生成本页；--check 重算比对、过期即红。

本页是生成物：数据由上面这条命令真跑 demo.py 现算（测试数按 tests/ 静态现数； 唯一实时测量=第 3 段耗时列，已按规则替换成 <当场>）。一切数字不外推为生产结论。
