# B25-nlp-lab —— 中文分词与朴素贝叶斯文本分类

**课程映射**：自然语言处理

零第三方依赖：正向/逆向最大匹配分词（FMM/BMM）、多项式朴素贝叶斯
（拉普拉斯平滑）、手写指标（混淆矩阵/P/R/F1）。语料为种子化模板生成的
合成中文消息（来源声明见下），分词词典与语料词池**同源管理**，
"语料回切不变式"测试担保三方不漂移。

## 运行

```
run.bat                        # 自测（25 项，含展示页 9 项）+ 四段演示
python tests\test_nlp.py       # 只跑自测
python demo.py                 # 只看演示
```

## 数据来源声明

合成语料 200 条中文消息（notice/spam 各 100），由 `nlp25/corpus.py`
按类别词池 + 固定种子模板生成。**词池几乎不重叠，准确率 1.00 显著好于
真实场景**——教学价值在"分词→特征→训练→评估"的流水线，不在指标数字。
真实语料（如 SMS 垃圾短信公开集）需要联网下载，待批准后作扩展。

## 课程知识点 ↔ 代码模块映射

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
| 正向最大匹配（贪心最长） | `segment.py` `fmm` | 首词=最长词典前缀（独立计算） |
| 逆向最大匹配 | `segment.py` `bmm` | 与 FMM 互为歧义探针 |
| **歧义与切分歧义句** | `segment.py` `segment` | "研究生命起源"：FMM 研究生/命/起源 vs BMM 研究/生命/起源 |
| 未登录词回退单字 | 同上 | 非词典输入不崩溃、拼接不变 |
| 拼接不变式 | 测试 | 切分拼回 == 原文 |
| 多项式朴素贝叶斯 | `bayes.py` | 两词表迷你语料后验手算 10/13 逐数断言 |
| **拉普拉斯平滑** | `bayes.py` α | 未见词不产生 log(0)；大 α 稀释置信度不改判别方向 |
| 朴素 = 条件独立假设 | `bayes.py` `_log_scores` | 词对数似然逐词相加 |
| 先验/后验 | 同上 | 手算 + softmax 归一和为 1 |
| 混淆矩阵 / P / R / F1 | `metrics.py` | 手算 TP/FN/FP/TN 对照；零除约定 0.0 |

## 实现时踩到的坑

1. **贪心最大匹配没有"词数最少"保证**：FMM 在"研究生命起源"上把
   "生命"拆坏。能断言的只有：结果合法（逐词 ∈ 词典或单字）、在全部
   合法切分的集合里、与 BMM 的分歧 = 歧义信号。第一版测试想断言
   "FMM = 词数最少的切分"，写之前手推了一个反例才作罢。
2. **语料相邻词拼出词典长词会破坏回切**：词池/词典/生成器三方必须
   同源（dictionary.py 单文件），并用"语料回切不变式"测试担保
   （每条消息分词后还原成生成时的词序列，200 条全查）。
3. **α=0 会让未见词产生 log(0)**：平滑参数必须 > 0，构造函数里拒绝。
4. **未见词的处理方式是实现决策**：本实现直接忽略（它对两类的似然
   贡献同为平滑常数）；另一种做法是 UNK 特殊词，写进练习。

## 测试策略（25 项 = 16 核心 + 9 展示页；25 项测试双入口同数）

- 分词：贪心性质（首词 = 最长词典前缀，独立计算）、拼接不变式、
  合法性与确定性、**FMM/BMM 歧义对拍**（手造歧义句）、短句穷举
  （FMM/BMM 结果 ∈ 全部合法切分集合）、单字回退
- 指标：手算 TP/FN/FP/TN 与 P/R/F1（含 2/3 这类精确分数）、零除约定、
  未知标签拒绝
- 贝叶斯：**两词表语料完整手算后验 10/13**、未见词忽略不改判别、
  α>0 约束、α 稀释置信度不改方向
- 语料与端到端：回切不变式（200 条全查）、确定性、固定划分准确率
  ≥ 0.95、两条手写新消息分类正确

## 已知局限

- 词典静态（自建 ~160 词），覆盖面仅限演示域；无新词发现。
- FMM/BMM 是贪心算法，歧义句正确率取决于扫描方向，无统计模型
  （HMM/Viterbi 在选做扩展，未做）。
- 贝叶斯的"朴素"假设在真实文本上不成立；合成语料夸大了效果。
- 二分类专用语料；metrics 支持多类但未演示。
