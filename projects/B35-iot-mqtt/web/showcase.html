怎么自己跑

  • run.bat：三步（测试 → 六段演示 → 展示页新鲜度）；DB 与 SVG 落在 build\。
  • python demo.py：六段演示；python tools\logdiff.py a.log b.log：两次日志规范化比对。
  • python tools\showcase.py --write：重新生成本页；--check 重算比对、过期即红。

本页是生成物：数据由上面这条命令真跑 demo.py 现算（测试数按 tests/ 静态现数； 两处【实测】数字已按规则替换成 <当场>）。零依赖：纯标准库。
