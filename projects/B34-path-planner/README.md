# B34-path-planner —— 栅格路径规划：A* / Dijkstra / BFS 同源对拍 + 搜索展开动画（无人系统）

**课程映射**：无人系统（PLAN 批次 7）。

一句话：**A*、Dijkstra、BFS 不是三个算法，是一个循环加一个参数**——`best_first()` 只换
启发式：h≡0 就是 Dijkstra，h=乐观估计就是 A*；BFS 只在"每步同价"的 4 邻域里与它们等价，
8 邻域斜步 √2 一出现就**明确拒绝执行**（抛 ValueError）而不是悄悄给错答案。规划结果不只
一条路，还有**搜索过程**：自包含 HTML 把"展开顺序"回放成动画（与 B33 同一条纪律——
页面只移动记录下标，不重算搜索）。

**范围声明**：栅格 A*（可配曼哈顿/欧氏/对角启发式）、障碍与无解场景、路径长度与运行时间
对比、可采纳性实测（max(h−真实)≤0）与不可采纳反例、自包含 HTML 搜索展开动画。**不做**
（PLAN 选做项）：RRT*、DWA 局部避障、PID 跟随。**动画观感**（动没动、清不清楚）属用户
实跑验收，自动化只覆盖到"记录保真 + 页面结构 + JS 语法"。

**复用/依赖声明**：优先队列用标准库 `heapq`（B12 同款决策：Python 侧不重复造 B2 的结构库）；
零第三方依赖、零下载。随机地图种子化，测试、演示、动画引用同一张图。

## 运行

```
run.bat                                   # 两步：20 项测试 → demo（生成 build\plan.html 并 node --check）
python -m unittest discover -s tests      # 20 项（双入口同数）
python tests/test_planner.py              # 直跑同 20 项
python demo.py                            # 六段：手算 → 对拍 → 对比表 → 可采纳性 → 反例 → 动画页
python tools/logdiff.py a.log b.log       # 两次日志规范化比对（规则两类，见脚本头，会打印计数）
```

**打开 `build\plan.html` 即可看搜索展开动画**：播放/暂停/单步/上一步/直接看结果/速度；
冷色越深展开越晚、红色是当前格、到终点后绿色高亮最终路径。数据内嵌单文件，双击即开；
无网络请求、无外部字体与脚本。

## 知识点 ↔ 实现 ↔ 怎么被验证

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
| A* 与 Dijkstra 同源 | `best_first(..., heuristic)` | 30 张种子图 × 双邻域：A* 代价 == Dijkstra（`assertAlmostEqual`）且扩展数 ≤（逐 seed 断言）；h≡0 直接就是 Dijkstra——同一函数，不是两份实现 |
| BFS 的适用前提 | `bfs()` 对 `allow_diagonal` 抛 ValueError | 20 张 4 邻域图与 Dijkstra 代价全等；8 邻域调用**必须报错**（测试钉住） |
| 启发式可采纳性 | `max_admissibility_slack`（从目标回溯的 Dijkstra 算真实距离） | 曼哈顿×4邻域 / octile×8邻域 / 欧氏×8邻域 slack ≤ 0（实测 +0.000）；曼哈顿×8邻域 slack ≈ +4.69（高估即撒谎，测试要求 >0.5） |
| 不可采纳 → 次优 | 种子搜索找真反例 | seed=3：Dijkstra 14.242641 vs A* 14.828427，差值 0.585786 = 2−√2（测试钉住精确值） |
| 无解与退化 | 围死场景 / start==goal / 非法端点 | 围死**确定性**无解（两次展开序列相同、原因非空）；start==goal 代价 0；障碍起点/越界终点抛 ValueError |
| 运动模型与几何 | 4/8 邻域、斜步 √2、防穿角 | 手算：3×3 对角 √2、1×3 走廊代价 2、绕墙小图代价 5；防穿角：两正交邻居皆墙时斜移被禁（邻居表为空） |
| 数据与视图分离 | `export_trace` → `build_page` | 页面内嵌 JSON 与 trace **逐字段相等**（`json.loads` 后 ==）；同一输入两遍构建**字节相同** |
| JS 语法 | `node --check` | 抽出 `<script>` 语法体检退出码 0；无 node 或不可执行时如实跳过，不冒充 |

## 实测（2026-10-02，首次交付；数字均为本轮现算）

- **20 项测试双入口同数**（`discover` 与直跑均 20 OK）；`run.bat` **两次退出码 0**、
  `build/` 外无新增、两次日志经 `tools/logdiff.py` 规范化后**逐字相同**（各 72 行；
  规范项 = 单测计时 1 + 第 3 段耗时 5，脚本会打印两侧计数供审计）。
- 对拍摘要（24×18、density 0.28、seed 1–30）：4 邻域 **30/30** 代价精确相等；
  10 图扩展数 Dijkstra **2380 → A* 1664**；8 邻域（octile）**29/30 精确相等**——
  差的 1 张是 seed=25 的**浮点求和次序**（差 7.105e-15 ≈ 1 ulp：
  35.89949493661167 vs …674），数学等价，测试用 `assertAlmostEqual`；
  无权图 4 邻域上 BFS 与 Dijkstra **20/20** 代价相等。
- 对比表（32×24、seed=9）：4 邻域代价 56.000、扩展 517 → 211；8 邻域代价 50.142、
  扩展 515 → 218（octile）/ 246（欧氏）；耗时列为【实测】毫秒级。
- 可采纳性 slack：三组合法配对 **+0.000**；曼哈顿×8邻域 **+4.686**。
- 反例（seed=3）：14.242641 vs 14.828427，差值 **0.585786 = 2−√2**。
- 围死：`found=False`、原因"目标不可达（开放表耗尽）"；start==goal：代价 0、路径 [(0,0)]。
- 动画页 `build/plan.html`：**10203 字节**、展开 **218 步**（32×24 大图）；
  `node --check` 退出码 **0**。测试自建小图页面 7644 字节（断言 >6000 兜"空壳页"）。

## 坑（都留了钉子）

1. **"围死"场景第一版没围死**：`walled_scene` 最初只封了目标一侧，目标仍能绕进去——
   被"应当不可达"的测试当场抓出（拿到 `found=True`）。构造失败场景时**必须让测试断言
   它真的失败**，否则演示讲的是另一回事。
2. **demo 从没在"干净目录"里跑过**：`demo.py` 写 `build/plan.html` 却从不建 `build/`，
   开发期间它一直碰巧存在（前次运行/测试留下）。收尾用 `rm -rf build` 复跑，首跑即
   `FileNotFoundError`——**干净复跑是交付的一部分**：新克隆目录下 run.bat 的第一次运行
   必须成立。已加 `mkdir(parents=True, exist_ok=True)`。
3. **精确相等与几乎相等要分开用**：8 邻域代价是 √2 的和，求和次序不同会在最后一位分道
   （seed=25 差 1 ulp）。对拍断言用 `assertAlmostEqual`（数学等价），演示计数用 `==`
   并如实打印 29/30——两个口径都写出来，比"四舍五入后全 30/30"诚实。
4. **阈值是量出来的**：页面尺寸断言第一版的下界写到了实测（7644 字节）之上，直接红——
   改成 `>6000`（留余量兜"页面被掏空"这类真事故），并写明实测值。
5. **临时目录的仓库守卫**（10-02 事故的钉子延续）：`make_tmp` 若发现临时目录落在仓库内
   直接抛错；`tearDownClass` 只删自己建的那一个目录。

## 明确不做（本期范围外）

RRT*、DWA 局部避障、PID 跟随与动态避障（PLAN 选做）；连续空间与任意多边形障碍；
三维或动力学约束规划；交互式地图编辑。页面不联网、不加载外部字体与脚本。
