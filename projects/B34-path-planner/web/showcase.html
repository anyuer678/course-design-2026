B34 路径规划 —— 搜索展开动画（A* / Dijkstra 同源）

数据内嵌于本页（来自 planner 的搜索结果导出）。播放/单步只是在移动"展开下标"， 页面不重算搜索。绿色为最终路径，冷色渐深表示展开次序，红色是当前展开的格子。

障碍 早期展开 晚期展开 当前展开 最终路径 起点/终点

怎么自己跑

  • run.bat：三步（测试 → demo（生成 build\plan.html）→ 展示页新鲜度）。
  • python demo.py：六段演示；打开 build\plan.html 点「播放」看搜索怎么展开。
  • python tools\showcase.py --write：重新生成本页；--check 重算比对、过期即红。
