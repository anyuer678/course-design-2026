# B1-cpp-ministl —— 手写 vector / list / string + 待办清单（计算机程序设计基础 C++）

**课程映射**：计算机程序设计基础(C++)（PLAN 批次 1）；同时是**程序设计基础实践**课的综合演示与
持久化底座（那门课复用本项目，不再复制第二套容器库）。

一句话：**容器的"对"不是自己说了算**——同一串随机操作分别喂给 `mini::vector` 与
`std::vector`（链表/字符串同理），每一步之后逐元素比对；差异由操作序列找出来，不是由我想出来。

**范围声明**：实现 `vector`（动态数组，倍增扩容）、`list`（带哨兵的双向链表）、
`string`（堆上字节串），五个特殊成员函数（拷贝/移动构造与赋值、析构）全部按 RAII 实现；
待办清单做增删改查与文件回读。**不做**（选做扩展，PLAN §4 已列明）：红黑树 map、`unique_ptr`、
通用 `sort`、分配器、完整强异常保证、SSO 优化。**异常安全只承诺基本保证**（不泄漏；不承诺
"失败后内容原封不动"），这一点在头文件里明说而不是留白。

## 重建时踩到的坑（都留了钉子）

1. **`c_str()` 的 `'\0'` 不是自动的**：构造函数拷贝完内容后忘了写终止符，
   `strcmp` 会读越界——测试里一条 `strcmp == 0` 当场抓住（size 对了、不代表门面对了）。
2. **`append(char)` 不能借道 `strlen`**：`'\0'` 走 `append(const char*)` 会被当成空串丢掉，
   待办里"内嵌 `'\0'` 回读"的用例因此红——现在 `append(char)` 直接写字节。
3. **修 bug 时引入了段错误**：给构造函数补终止符时没防"空串不分配缓冲"，
   `data_[0] = '\0'` 写空指针，直接段错误——**空串是边界**这句话在字符串上尤其真。
4. **多字符常量 `'闭'` 是编译期陷阱**：UTF-8 汉字写进 `char` 字面量是 multichar 常量
   （`-Wmultichar` + 溢出警告）。查字符要用 `find("闭")`（按字节子串查找），
   并顺带演示"substr 按字节、两个汉字 6 字节"。

## 明确不做（本期范围外）

红黑树 `map`、`unique_ptr`、通用 `sort`、分配器与内存池、SSO、完整强异常保证、
`vector<bool>` 位压缩、list 的 `splice/sort`。也不假装线程安全（并发容器完全不在本课范围）。
