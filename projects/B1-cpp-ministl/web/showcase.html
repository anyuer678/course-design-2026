展示区

每段都是 ministl-demo.exe 的现场输出。

1) vector：增长曲线、遍历、拷贝独立（RAII 管缓冲区）
  第  1 次 push：size=1 capacity=4（刚换了缓冲）
  第  5 次 push：size=5 capacity=8（刚换了缓冲）
  第  9 次 push：size=9 capacity=16（刚换了缓冲）
  内容：1 4 9 16 25 36 49 64 81 100 （size=10，capacity=16）
  改 v[0]=-1 之后：v[0]=-1，副本[0]=1（深拷贝，互不影响）
2) list：头尾插入、正反向遍历（插入不使其他迭代器失效）
  正向：列计划 / 写代码 / 测试 /
  反向：测试 / 写代码 / 列计划 /
  头插“开会”后，之前指向中段的迭代器仍读作：写代码
3) string：拼接、查找、子串、自追加（按字节记账）
  拼接后：离散结构：闭包（size=21 字节——UTF-8 下一个汉字 3 字节）
  find("闭")=15（字节偏移）；substr(0,6)=离散（6 字节 = 两个汉字）
  "ab" 自追加两次：abababab（size=8，悬垂坑已被处理）
4) 待办清单：CRUD → 存盘 → 回读逐字段对账 → 清理
  内存中（2 条；再删一条不存在的是否报错=否）：
   id  完成  文本
   1    是    买牛奶
   2    否    写课设 README（补测试）
  存盘到 build\todo_demo.txt
  回读 2 条，逐字段对账：一致
  回读后追加一条，id 从 3 继续（不重号）
  演示文件已删除：是
5) 与 std::vector / std::list / std::string 随机对拍（种子固定）
  vector 对拍：12 种子 × 80 步 = 14907 项逐元素检查，0 失败
  list   对拍： 8 种子 × 80 步 = 22960 项逐元素检查（含反向遍历），0 失败
  string 对拍： 8 种子 × 80 步 = 26439 项逐次对照（含自追加），0 失败
  合计 64306 项检查
