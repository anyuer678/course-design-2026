# B39-tech-radar —— 技术雷达：主题记录模板 + 可机验证据 + 一次最小复现（专业前沿技术讲座）

**课程映射**：专业前沿技术讲座（PLAN 批次 8 / 毕业出口）。

一句话：技术雷达的坑不在"记不记"，在**记的内容没人能核验**——本项目把记录变成
半张"可执行文档"：模板强制五节（问题/原理/证据/局限/复现），
**检查器把「证据」从"据说"变成指针**（反引号里的仓库路径必须存在、`@提交号`
必须在 git 里存在），再给一次完整的最小复现示范（**CRDT 的收敛性**：
交换/结合/幂等三条性质 → 最终一致，性质可跑、可改坏看红）。

**用法（真实条目由你自己填写）**：复制 `docs/record-template.md` 到
`docs/records/<主题>.md`，照实填写口来源——填完一定要跑
`python tools/check_record.py docs/records/<主题>.md`，**红了不算记录**。
仓库内自带的 `docs/records/example-crdt.md` 明确标注「示例（非真实来源）」，
检查器会强制这个诚实标记。

## 运行

```
run.bat                                   # 三步：26 项测试 → demo（四段；无计时输出）→ 展示页新鲜度
python -m unittest discover -s tests      # 26 项（18 核心 + 8 展示页）
python tests/test_radar.py                # 直跑同 18 项（本文件）
python demo.py                            # 模板/检查器 → 负面对照 → CRDT 复现 → 使用指引
python tools/check_record.py docs/records/example-crdt.md    # 单检一条记录
python tools/logdiff.py a.log b.log       # 两次日志规范化比对（规则只剩 unittest 计时）
python tools/showcase.py --write          # 重生展示页 web/showcase.html（--check 过期即红）
```

零依赖：纯标准库 + git（校验提交号证据用；缺 git 时检查器明确报"无法核验"）。

## 知识点 · 实现 · 怎么被验证

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
| 记录结构可执行 | `REQUIRED_SECTIONS` 顺序检查 | 示例记录 PASS；删「局限与适用边界」→ 必须 RED（对照测试钉住） |
| 证据 = 可核验指针 | `check_record.py` 指针解析 | 路径不存在/假提交号各有一条"改坏必须红"的对照；示例里 4 路径 + 1 提交逐条真验 |
| 诚实标注 | 来源含「示例」必须写「非真实来源」 | 去掉标记 → RED（对照测试） |
| CRDT 收敛的数学 | `crdt_lww.py` merge=取 ts 较大 | 交换律/结合律/幂等（各 50 组随机）+ 100 组随机置换全部收敛到同一 (值, 时间戳) |
| 全序破平 | `Timestamp(counter, replica)` | `test_tie_break_by_replica`：并列计数器时按副本号取大，两侧顺序无关 |
| 协议违规要响 | 合并守卫 | 同一 (计数器, 副本) 两个值 → ValueError（防"悄悄按到达顺序取一个"的误解） |
| 独立参照 | 收敛测试的期望值 | 用 `max()` 手算赢家当参照，而不是拿合并器自己证明自己 |

## 坑（都留了钉子）

1. **"改坏必须红"是检查器存在的证明**：三条负面对照（各对应一条规则）进测试——
   结构检查、路径检查、提交检查任何一个失灵，测试当场红，检查器不会退化成装饰。
2. **口径必须写进模板（第一次负面对照没红的现场证明）**：假提交测试第一版 Expected RED、
   实际 0 问题——因为示例里的 `@f0bb729` 当时是**裸写**的，而检查器只认**反引号内**的指针，
   两处都没错、是"契约没写清"。修正：示例补上反引号 + 模板里把指针写法写成显式规则；
   教训与前几轮同源：**规则的可信度取决于"触发条件"是否写得没有歧义**。
3. **GBK 扫净第三次复发**：双线箭头推导符号（U+21D2）又出现在新写的文件里（B37/B38 已各修过一次）——
   全源码扫查已变成每轮收尾的固定动作，这次它当场抓住两处。
