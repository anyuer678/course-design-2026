# B27-course-kg —— 课程先修知识图谱

**课程映射**：知识图谱与知识工程

用**本仓库自己的 41 门任务与 PLAN §3 的先修依赖**做知识图谱：
data/ 下两份 CSV 就是三元组的事实源（任务节点 + 带来源的关边），
`kg/graph.py` 提供拓扑排序、先修闭包（传递闭包）、缺先修检测、
学习路径生成；`kg/viz.py` 手写 SVG 分层布局生成**自包含交互 HTML**
（点击节点高亮其全部先修与解锁后继，零外部请求）。
自带一个自指彩蛋：图谱里有一条 B3（离散结构）→ B27（本项目）的边。

## 运行

```
run.bat                        # 自测（14 项）+ 四段演示
python tests\test_kg.py        # 只跑自测
python demo.py                 # 演示（HTML 写到临时目录，退出即清理）
```

## 课程知识点 ↔ 代码模块映射

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
| 三元组 (头, 关系, 尾) | data/prereqs.csv | 每条边带 kind（先修/概念支撑/迭代阶段）与来源 |
| 有向图邻接表 | `graph.py` `_succ/_pred` | 双向索引，直接先修/直接后继 O(1) |
| **传递闭包** | `graph.py` `ancestors/descendants` | 与测试内独立 DFS 交叉验证（15 个任务） |
| 拓扑排序（Kahn） | `graph.py` `topological_order` | 全图 41 节点、每条边 u→v 满足 pos[u]<pos[v] |
| 环检测 | 同上 | 有环抛异常（`validate`） |
| **缺先修检测** | `missing_prereqs` | 手工构造迷你图 + "做 B18 还缺什么"两场景模拟 |
| 学习路径 | `learning_path` | 先修闭包子图的拓扑序，路径合法性逐边断言 |
| 图可视化（分层布局） | `viz.py` `_layers` | 层号 = 最长路径深度，边永远从浅层指向深层 |
| 自包含交互页面 | `viz.py` `render_html` | 41 节点/41 边全出现；无任何外部请求 |
| 数据与代码分离 | data/*.csv | 图不硬编码边；CSV 行与内存图一一对应 |

## 一条边的来源都可查

`prereqs.csv` 每行带 `source` 列（如 `PLAN§3 系统基础`、`批次5 验收顺序`），
没有一条边是凭空画的。三种关系：
- **先修**：硬依赖（如 B5→B9，B14→B15）
- **概念支撑**：有帮助但非硬性（如 B2→B10 的 SQL 概念、B10→B30 的恢复概念）
- **迭代阶段**：批次 5 同一系统的验收顺序（B15→B16→…→B22）

独立任务（B4 集合论、B24 视觉、B36 鸿蒙、B39–B41）在 PLAN §3 中没有
依赖边，图中如实保持孤立——"没有证据的边不画"。

## 实现时踩到的坑

1. **数据缺边，测试抓的**：PLAN §3 明文有"B31 → B32 的 Web 安全实验"，
   CSV 转写时漏了这条——`test_descendants_unlock` 断言 B11 的下游应含
   B32 而失败。图谱的"事实源 + 断言"结构把转写遗漏变成了机器可见的红。
2. **测试方法里误用 `cls`**：setUpClass 的类属性在实例方法里要用
   `self`，三处 NameError 是同一处笔误。
3. **演示断言的白名单手写漏项**："做 B18 缺什么"的白名单漏了 B11
   （B18 ← B15 ← B31 ← B11 的间接先修）。改成直接断言
   `missing == 闭包 − 已完成`——期望值跟着定义走，不跟手抄走。

## 测试策略（14 项）

- 数据：41 任务、8 个批次、边端点存在、validate 无环
- 闭包：独立 DFS 交叉验证（15 个任务抽样）；PLAN §3 明文链逐数断言
  （B9 闭包 = B1/B2/B5/B6/B8；B11 下游含 B31/B30/B35/B38/B37）
- 查询：缺先修手算（迷你图三场景）、ready_tasks 解锁模拟、
  learning_path 合法性与顺序断言
- 可视化：41 节点与全部边出现、自包含（无 http 外链）、闭合标签

## 已知局限

- SVG 分层布局是确定性的朴素排布，密集时边会交叉（教学可读优先）。
- 交互只有"高亮闭包"，无拖拽/缩放（手写 SVG 的取舍）。
- 关系只有命名类别，没有属性图（权重、学期等）。
- `learning_path` 不做学期负载均衡——它是"依赖合法序"不是"课表"。
