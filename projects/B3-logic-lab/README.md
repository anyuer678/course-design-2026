# B3-logic-lab —— 命题逻辑 + 二元关系（离散结构）

**课程映射**：离散结构（PLAN 批次 1）。

一句话：**判定不靠化简，靠穷举**——真值表把 2^n 行全枚举出来，"重言/矛盾/可满足"、
主析取/合取范式、两式等价全部由它导出；关系那半场同理，性质判定按定义逐格检查，
传递闭包用两套独立实现（Warshall 与逐点 BFS）互相对拍。

**范围声明**：支持变量（字母或字母+数字）、`~ & | -> <=>`、括号与常量 `0/1`；
真值表/极小项/极大项/主范式（可回代复验）、可满足性、等价判定；关系矩阵的性质判定
（自反/反自反/对称/反对称/传递）、三种闭包、等价类与划分校验、偏序判定。
**不做**：谓词逻辑、公式化简与最小化（Quine–McCluskey 之类）、图论算法本身
（B12 求最短路/MST，B27 做分层图）、把 Warshall 当唯一真理（BFS 才是独立参照）。

## 知识点 ↔ 实现 ↔ 怎么被验证

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
| 优先级与结合性 | `_Parser` 的五层函数链 | `render` 的括号位置逐条手推（`~` > `&` > `|` > `->` > `<=>`；`->` 右结合） |
| 两字符运算符 | `tokenize` | `p->q`、`p<=>q` 必须切成 3 个记号；`p<q`、`p - > q` 报错并给字符位置 |
| 词法/语法错误定位 | `FormulaError.pos` | 9 组坏输入断言字符下标（`"p &"` 报在 3、`"(p & q"` 报在 6） |
| 真值表（语义定义） | `truth_table` | `p & q` 的 4 行**逐行手写**对照；行序 = 变量字典序的二进制计数 |
| 极小项/极大项 | `minterms` / `maxterms` | 两者恰好覆盖 `0..2^n-1` 且不重（多条公式断言） |
| 主范式 = 表的两半 | `to_dnf` / `to_cnf` | 逐字符断言；**回代验证**：把输出喂回解析器再判等价 |
| 极大项极性 | `to_cnf` 的取反方向 | 专项测试：`p & q` 的合取范式逐字符对照（写反立刻红） |
| 重言/矛盾/可满足 | `is_tautology` 等 | `p \| ~p` 与 `p & ~p` 两个极端；退化情形输出 `1` / `0` |
| 等价判定 | `equivalent` | 德摩根、逆否对拍；变量集合不同按**并集**补全（`p` vs `p & q` 为假） |
| 关系性质按定义 | `Relation` 谓词 | 恒等/空关系/互反点对/严格序/整除，手推矩阵逐条断言 |
| 反对称 ≠ 不对称 | `is_antisymmetric` | 恒等关系（对角线不受限）也是偏序；互反点对不是反对称 |
| 传递闭包 | `transitive_closure_warshall` | 与 `transitive_closure_bfs` 在**固定种子**随机关系上逐格对拍（>400 格） |
| 闭包性质 | 三种闭包 | 闭包自反/对称/传递；原关系 ⊆ 闭包；对称闭包幂等 |
| 等价类与划分 | `equivalence_classes` / `check_partition` | mod 3 三分类；并集=全集、两两不交；**非等价关系拒绝划分**（不是硬算） |
| 偏序 | `is_partial_order` | 整除关系（{1..6}，14 条边）；`<` 加自反闭包变 `≤` 后成为偏序 |

## 重建时踩到的坑（都留下了钉子）

1. **两字符运算符必须先试长的**：`->` 若按单字符切，会变成 `-` 与 `>` 两个坏记号——
   `<=>` 同理。词法里"先试两字符再试单字符"的次序是规范的一部分。
2. **极大项的取反方向写反是经典错误**：成真的行取变量本身、成假的行取否定；
   `to_cnf` 有一条逐字符测试盯着它（写反后输出与原式不等价）。
3. **变量序是规范**：极小项编号依赖**字典序**（`p1 < p10 < p2` 的字符串序），
   顺序一变编号全变；`variables()` 的排序那行不允许"顺手"改。
4. **给 AST 加常量后差点把收集逻辑写丢**：我改写 `walk` 时把 `Var` 分支的 `found.add`
   丢了，`variables()` 返回空——测试第一轮就红（`KeyError: 'p'`）。
   这就是"每条规定都有测试钉住"的用途。
5. **`render` 的括号只按树形加，不做最简化简**：`~(p & q)` 会渲染成 `~((p & q))`。
   文档原来写"最少括号"，实测不符 → 已改成如实描述（演示里也把标签改成"结构还原"）。

## 明确不做（本期范围外）

谓词逻辑与量词；公式化简、范式最小化、Quine–McCluskey；真值表超过 ~16 变量时的性能优化
（穷举的代价是指数级，本项目把这一点当教学事实而不是缺陷）；关系上的图论算法
（最短路/MST/拓扑排序在 B12/B27）；代数结构（群/环/域）留给 B4。
