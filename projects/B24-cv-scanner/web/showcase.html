怎么自己跑

  • run.bat：三步（测试 → 六段演示 → 展示页新鲜度）；PNG 产物落在 build\。
  • python demo.py：六段演示；python -m unittest discover -s tests：全量测试。
  • python tools\showcase.py --write：重新生成本页；--check 重算比对、过期即红。
