# 14 风险登记册（B22）

管理文档里最常见的一类假动作是"风险清单"——列一堆谁都知道的道理，然后没有任何东西会因它变红。
这份登记册有两个约束：

1. **每条未决需求都必须在册**：`docs/05` 里所有未裁决的 AQ（当前 `L:aq_open=9` 条，共 `L:aq_total=12` 条）
   必须在下面的表里各有一行；多登记一条已裁决的、或漏一条未决的，`checks/check_pm.py` 直接红。
2. **每条工程风险都要写"怎么知道它发生了"**（触发信号）。写不出触发信号的条目等于愿望，不叫风险。

数字一律用 `L:键=值` 台账标记，见 `docs/13` 第 1 节。

## 3. 优先级（我的判断，不是事实）

按"影响面 × 现在就能处理成本"排：

1. **待决需求里先问 AQ-06 与 AQ-02**——它们决定统计与验收口径，且只有你能给答案；

4. AQ-10 / AQ-11 已经有量化数字，可以放到有真实班组口径之后再裁。
