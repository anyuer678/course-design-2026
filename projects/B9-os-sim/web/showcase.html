Belady 异常：FIFO 从 3 帧到 4 帧，缺页反而变多（9 → 10）。

注意：LRU ≤ FIFO **不成立**（本串 LRU=10 > FIFO=9），能断言的只有 OPT ≤ 任何算法。

  • 初始安全性：安全 序列：P -> P1 -> P3 -> P4 -> P0 -> P2
  • P1 请求 (1,0,2)：批准，序列长度 5，Available 变为 (2,3,0)
  • P4 请求 (3,3,0)：拒绝（资源不足：此刻无法满足，进程等待）
  • P0 请求 (0,2,0)：拒绝（分配后系统不安全：拒绝并回滚）；回滚后 Available=(2,3,0)

"不安全就拒绝并回滚"是重点：拒绝之后的 Available 必须回到请求前的值。

  • 写 a.txt(8B) -> 链 2 块，首块 0，空闲 14
  • 删 a.txt 再建 c(4B)：c 复用块 0（第一次分配从低块号开始）
  • 满盘写新文件：失败并被回滚——keep 内容完好=是，空闲块数不变=是

分配失败既不泄漏块也不破坏旧内容——测试里专门有满盘/空文件/失败回滚的边界断言。

  • 投递 40000、取走 40000、水位 8（容量 8）；逐条比对（不丢不重不错值）：全部对上

4 线程（2 生产者 + 2 消费者）10 万条消息逐条比对：不丢、不重、不错值。
