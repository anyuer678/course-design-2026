怎么自己跑

  • run.bat：五步（编译 → 自检 → 离屏演示 → 展示页新鲜度 → 打开窗口）； run.bat no-gui 跳过窗口（构建在 %TEMP% 里，项目目录零残留）。
  • java -Djava.awt.headless=true -cp build\classes paint.App --demo：只看离屏演示。
  • python tools\showcase.py --write：重新生成本页；--check 重算比对、过期即红。

Swing 窗口的手感、键盘与拖拽的真实表现请自己开窗口试——自动化只到离屏语义这一层。
