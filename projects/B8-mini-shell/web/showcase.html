B8-mini-shell 演示：fork/exec、管道、重定向、内建命令与子进程回收

==============================================================================
  1) 命令执行与退出状态
==============================================================================
  `true` 退出码                0
  `false` 退出码               1
  `exit 42` 退出码             42
  echo 输出                   'hello from msh\n'

==============================================================================
  2) 内建命令 cd/pwd：改的是 shell 自己的进程状态
==============================================================================
  pwd → cd /tmp → pwd       <项目根>/build/demo_tmp → /tmp
  说明                        cd 若走 fork+exec，改的是子进程的 cwd，shell 自己不动——所以必须内建

==============================================================================
  3) 管道：N 个进程 + N-1 根管子
==============================================================================
  printf | sort | head -2   'a\nb\n'
  管道 $? = 最后一段              1
  反过来                       0

==============================================================================
  4) 重定向：> 截断 / >> 追加 / < 读入 / 管道落盘
==============================================================================
  echo first > out.txt 后    'first\n'
  再 echo second >> 后        'first\nsecond\n'
  sort < in.txt             'x\ny\nz\n'
  printf | sort > sorted.txt'a\nb\n'

==============================================================================
  5) 子进程回收：0 僵尸（/proc 当面数）
==============================================================================
  3 条命令跑完后，僵尸子进程            0 个
  未回收的直接子进程                 0 个

==============================================================================
  6) 错误路径：报错、退出码、继续执行
==============================================================================
  找不到命令 → stderr            'msh: no_such_command_xyz: No such file or directory'
  随后 echo 仍执行               'still alive\n'
  3 条坏语法的 stderr 条数         3
  最后仍输出                     'done\n'

==============================================================================
完成：6 段演示全部跑通（工作目录 build/demo_tmp 已清理）。

八个命令脚本逐个喂给 ./build/msh（stdin 重定向，非交互）， 每步打印输出与 msh 自身的退出码——管道口径、重定向落盘、内建 cd、错误路径都在这一段里现场发生。

--- 1) 三段管道：printf c/b/a | sort | head -2 ---
    | a
    | b
    -> msh 退出码 0

--- 2) 退出码口径：管道 $? = 最后一段 ---
    -> msh 退出码 1
    -> msh 退出码 0

--- 3) 重定向：> 截断、>> 追加，再 cat 回读 ---
    -> msh 退出码 0
    | first
    | second
    -> msh 退出码 0

--- 4) 内建 cd 改的是 shell 自己的 cwd（同一会话里跨行保持）---
    | <项目根>/build/showcase_tmp
    -> msh 退出码 0

--- 5) 错误路径：找不到命令 -> 127；报错后继续执行 ---
    | msh: no_such_command_xyz: No such file or directory
    -> msh 退出码 127
    | msh: no_such_command_xyz: No such file or directory
    | still alive
    -> msh 退出码 0
