# B4-algebra-rsa —— 数论底座 + 教学 RSA + 群运算表判定（集合论与代数）

**课程映射**：集合论与代数（PLAN 批次 1）。

一句话：**定理要靠对拍背书**——扩展欧几里得与"两套实现互拍 + 裴蜀恒等验算"一起交付，
快速幂拿内建 `pow(a, e, m)` 当参照，欧拉函数筛法版和分解版逐数对拍，CRT 拿暴力搜索对拍，
群判定器直接对着真群（Z_n*、S_3）和四张手写的坏表验收。

**红线（写在最前）**：**教学 RSA 不用于真实秘密保护**。三条简化当面演示：
小素数当钥匙（筛法池里选）、**确定性加密**（同一明文两次加密密文相同）、无填充/无签名。
真实系统需要大素数生成（Miller–Rabin）、随机填充（OAEP）、签名与侧信道防护——都是 PLAN 选做项，**没做**。

**范围声明（PLAN §4）**：扩展欧几里得、模幂、欧拉函数、CRT；教学 RSA 回读；群运算表判定；
集合论小工具（运算/幂集/笛卡尔积/容斥/函数性质）。**不做**：米勒–拉宾、原根、BSGS、
大整数与签名、子群/生成元。

## 知识点 ↔ 实现 ↔ 怎么被验证

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
| 扩展欧几里得与裴蜀等式 | `egcd` / `egcd_iter` | 手算 (240,46)→(2,−9,47)；**两套独立实现 3721 组互拍**；`a·x+b·y=g` 2601 组验算；g == math.gcd 对拍 |
| 模逆 | `mod_inverse` | 手算 3⁻¹ mod 11 = 4、7⁻¹ mod 40 = 23；不互素**必须抛错**；对 m<60 全量逐个乘回去验 1 |
| 平方-乘快速幂 | `mod_pow` | 内建 `pow(a,e,m)` 当参照，**3000 组随机对拍**；乘法次数的账精确到"平方=bit_length−1、乘法=二进制 1 的个数" |
| 欧拉函数 | `phi`（分解）/ `phi_sieve`（筛法） | 手算 φ(1)/φ(9)/φ(97)/φ(100)；**1..400 逐数对拍**；经典恒等 Σ_{d|n}φ(d)=n 对 1..200 全验 |
| 中国剩余定理 | `crt` | "物不知数" 3,5,7 → 23；**300 组随机系统对暴力搜索**（在 [0,∏m) 里逐数试）；模数不互素抛错 |
| 素性与筛 | `is_prime` / `sieve` | π(100)=25；**0..2000 逐个与筛法对拍** |
| 教学 RSA | `rsa.py` 四函数 | e·d≡1 (mod φ) 验算；**200 条随机消息回读 + m=0/1/n−1 边界**；文本逐字节回读；越界抛错；确定性加密当面演示 |
| 群的四条定义 | `check_group` | Z_n 加法（n=1..12）全过；Z_n*（n=3..12）全过；**坏表四连**（不封闭/无单位元/缺逆/不结合）被拒并给反例 |
| 结合律是 O(n³) | `check_group` | n=5 的群打印"125 组三元"、n=8 是 512 组——次数是数出来的 |
| 阿贝尔与非阿贝尔 | `is_abelian` / `abelian_witness` | Z_8*（Klein 四元群：每元自乘=1、最大阶 2）；**S_3 置换复合**被认出是群且不交换（反例打印） |
| 容斥原理 | `inclusion_exclusion` | 一般式（逐子集交集）对暴力并集，**300 组 2~4 个集合对拍** |
| 幂集/笛卡尔积 | `power_set` / `cartesian` | 2³=8、2⁴=16；|A×B|=|A|·|B|；含空集/全集 |
| 函数三档性质 | `check_function` | 双射判定手算；三类"不是函数"分开报；**3→3 全部 27 个映射穷举出 6 个双射 = 3!** |

  300 组 CRT 暴力对拍、2001 个素性判定、300 组容斥对拍。

## 重建时踩到的坑（都留了钉子）

1. **GBK 控制台编不了上标字符**：演示里写 `2³`/`n³` 直接 `python demo.py` 时
   `UnicodeEncodeError`（run.bat 有 PYTHONUTF8 不受影响，但**演示本身要能在默认控制台跑**）。
   全部换成 `**3` 写法，并把"全套源码无 GBK 不可编码字符"做成一次扫描——这样连
   **traceback 打印源码行**也不会二次崩溃。
2. **期望值也要先手推**：我给"非交换 witness"随手写了一张表，测试却红了——
   那张表其实是对称的。换成 **S_3 置换复合表**（程序化构造）才是真正的非交换例子，
   顺带把"最小的非交换群"变成了断言。
3. **`(0,0)` 的约定要两边一致**：egcd 递归版给 `(0,0,0)`、迭代版初版给 `(0,1,0)`——
   互拍测试当场逮住。两版统一成"g=0 时系数全 0"并写进注释。
