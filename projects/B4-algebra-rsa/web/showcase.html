展示区

教学 RSA（明文 -> 密文 -> 回读）

密钥（seed=42，确定性生成）：p=983  q=127  n=p·q=124841  φ=(p-1)(q-1)=123732
公开指数 e=65537    私密指数 d=1601（e·d ≡ 1 mod φ）
明文 m=2025   加密 c=m^e mod n = 116468   解密 c^d mod n = 2025
往返校验：成功
文本「B4 数论演示」→ 分块密文 [27459, 16278, 90299, 65823, 40438, 38689, 4901, 81353, 91087, 65823, 87222, 5957, 79043, 91162, 91087] → 回读「B4 数论演示」：逐字节一致
同明文再加密一次：密文相同（c1 == c2）

红牌：这是教科书 RSA——确定性、无填充、小素数。同明文两次同密文（如上）意味着 可猜测攻击成立；它只用来讲原理，绝不用于真实秘密保护。工程上的修法（OAEP 填充、大素数、恒定时间运算） 在 README 的练习里。

数论底座（成本是数出来的）

egcd(1071, 462)：g=21，x=-3，y=7（递推版）
              迭代版 给出相同结果
Bézout 验证：1071·x + 462·y = 21：成立
mod_pow(7, 65537, 1e9+7) = 95353359
  平方-乘：18 次乘法；朴素逐个乘：65536 次 —— 差 3640 倍
mod_inverse(17, 3120) = 2753（教学密钥里 d 就是用它在算）
CRT：x ≡ 2 (mod 3) ≡ 3 (mod 5) ≡ 2 (mod 7) 的解 x = 23
  逐项验证：23 % 3 = 2（期望 2）、23 % 5 = 3（期望 3）、23 % 7 = 2（期望 2）
