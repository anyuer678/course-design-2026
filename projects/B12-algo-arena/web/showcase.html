怎么自己跑

  • run.bat：自测 + 演示（DP 表与方案还原 / 三种贪心对照 / N 皇后解数表 / Dijkstra 快照 / 规模计时）。

  • python tools/showcase.py --write：重新生成本页；--check 重算比对、过期即红。
