## 总结与展望

- **局限**（如实，来自 SECURITY §七）：无 HTTPS/2FA、非容器级隔离、单机单进程；
- **可扩展方向**：HTTPS 反向代理、任务提交式实验（队列化）、导出成绩单、课程资料上传、
  多机部署（把 SQLite 换掉时领域层不动）。
