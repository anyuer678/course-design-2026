# CourseLab 安全边界报告

本文汇总平台**实际实现并进入自检**的安全边界（不是"打算做"的清单）。
对应代码：`server.py`、`app/auth.py`、`app/can.py`、`app/admin.py`、`app/labs.py`。

## 一、网络边界

| 边界 | 实现 | 证据（自检项） |
|---|---|---|
| 默认只绑回环 | `bind=127.0.0.1` 默认；`0.0.0.0` 需要显式配置/`--host` | 全平台默认行为 |
| 同源基线（CSRF 基线） | 带 `Origin` 的 POST 只放行本机同源，跨源 403 | "跨源 POST 被拒（同源基线）" |
| 内容源代理防穿越 | `/repo/` 解析后必须仍在仓库根内，否则 404 | "目录穿越（仓库外真实文件）被拒" |
| Cookie | `HttpOnly` + `SameSite=Lax` + `Path=/`，登出/封禁即失效 | "登出后旧会话失效"、"封禁即下线" |

## 二、账号与会话

- **口令**：PBKDF2-HMAC-SHA256，逐用户 16B 盐，120000 迭代；比对用 `hmac.compare_digest`。
- **会话**：随机 256-bit 令牌 + 服务端会话表（可强制下线）；默认 12 小时，可配。
- **登录限流**：同"用户名+IP" 10 分钟失败 5 次 -> 429（防口令爆破）。
- **改口令**：校验旧口令（失败计入同一限流，防会话被盗后爆破）；新口令强度与注册一致；
  改后**其他会话即时失效**、当前会话保留（自检含"旧口令登录 401 / 新口令 200 / 另一会话失效"）。
- **封禁**：管理员封禁即时（删会话）+ 登录 403；**待审批**用户不能登录（403 USER_PENDING）。
- **防锁死**：管理员不能改自己的角色 / 封自己（自检有负面用例）。

## 三、权限模型（判定唯一源）

- 所有接口在服务端判定（`app/can.py` 矩阵 + `admin.teacher_can_manage` 对象级绑定），
  前端只读判定结果，不复制规则；
- 对象级：教师只能管理**绑定给自己**的课程（管理端绑定）；学生不能调教师/管理接口；
- 实验日志/记录：只能看与停**自己的**运行（教师/管理员按授权放宽）；
- 公告可见性（`app/notices.py` 单一出处）：全员公告全员可见；课程公告仅管理员/绑定教师/
  在该课有任务或实验记录的学生可见；教师发未绑定课与全员公告一律 403（自检含负面用例）。

## 四、在线实验沙箱（本平台最大攻击面，边界写死）

| 风险 | 边界 |
|---|---|
| 任意命令执行 | **固定命令表**：客户端只能选 `项目 × 动作 id`，命令/参数/路径都在服务端写死 |
| 资源耗尽 | 并发上限（默认 2）+ 单实验超时（默认 600s，到点**整树杀**）+ 手动强停 |
| 孤儿进程 | 进程树统一 `taskkill /F /T`（Windows）/ terminate（POSIX）；平台退出 atexit 清理 |
| 越权启动 | 需登录 + `lab_run` 权限；每项目单进程；请求项目必须在课程目录里 |
| 不可审计 | 每次运行落库（谁/何时/项目/动作/kind/exit/日志尾），管理端可查与强停 |

## 五、输入与注入

- 所有 SQL 走参数绑定（`?`），无字符串拼接；
- 路径类输入（`/repo/`、课程 id、任务 key）都有白名单/正则/解析后前缀校验；
- 前端全部用 `textContent` 组装（无 `innerHTML`），用户内容（备注等）不会被当 HTML 执行；
- 任务备注长度截断（200 字符）、显示名/标题等都有长度与格式校验；
- **畸形输入边界**（M10 探针审查）：全部写接口 16 类错类型载荷均 4xx、0 崩溃；
  类型校验在 `set_course_meta` 单处判定（`published` 必须布尔、`summary/outline` 必须文本、
  `teacher_id` 必须整数）；`Content-Length` 非数字按 0 处理、超 1MB 截断，不进异常路径。

## 六、部署建议（公网/课堂）

1. `registration=approval`（白名单制）；
2. `max_labs` 保持小值（2-4）；
3. 每天 `tools/backup.py`；
4. 若挂公网，前置 HTTPS 反向代理（本平台自身是明文 HTTP——**已知局限**），
   或仅在 VPN/校园网内使用。

## 七、已知局限（如实声明）

- 本平台是**单机教学系统**：无 HTTPS、无 2FA、无 WAF；公网裸奔不在设计目标内；
- 实验沙箱是"白名单命令 + 限额"，**不是容器/虚拟机级隔离**——能跑的本来就是你自己的课程项目；
- Python 进程对高并发慢请求的韧性有限（实测 200 请求/8 并发 ≈ 458 req/s，课堂规模足够）；
- 管理动作审计已覆盖全部管理端**变更入口**（角色调整 / 状态封禁 / 课程治理 / 公告发布四类，
  管理端"管理动作"面板可查，自检含四类留痕断言）；审计本身未做防篡改链——持有 app.db
  文件者可改写记录（单机教学系统的边界，不引入区块链/外部日志服务）。
