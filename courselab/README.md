# CourseLab 课程工坊 —— 课程项目平台（毕设工程）

**每个课程各有一个小型项目平台**：把课设仓库里的 33 个项目、自包含展示页、实验台与练习册，
升格成一个能登录、能在线运行、能管理、能部署的 Web 平台（一份底座，每门课程一个工作区）。

- 定位与里程碑：`docs/PLAN.md`（角色矩阵 / 功能面 / 架构 / 里程碑 M0–M6）
- **详细设计（开工规格）**：`docs/DESIGN.md`（多端三端 / 18 个功能点 F1-F18 / 页面路由 /
  数据模型 / API 草案 / 部署设计）
- 现状：**M0–M4 已交付**——账号与会话、33 门课程工作区、项目页（详情/在线演示/在线实验）、
  **练习任务闭环**（G2 卡片任务领取/完成/进度 + 教师布置 + 本课统计）。已经"能用"：
  注册/登录/登出（PBKDF2 + 会话表 + 失败限流）、课程目录（搜索/批次筛选）、
  在线实验（跑演示/测试/服务，SSE 实时日志、并发限额、审计）、
  练习任务（领取→完成→备注→进度条→"我的任务"）、教师台（布置/删除任务、完成统计、最近动态）。
  下一步 M5 管理端（用户/课程治理 + 平台看板）。

## 角色与教师账号

- 注册的账号默认是**学生**；
- 教师/管理员用命令行提升（先注册，再提升）：
  `python server.py --promote 用户名 teacher`（或 admin），立即生效；
- 教师台入口：登录后顶栏「教师台」（/teacher.html）。

## 运行

```
双击 run.bat            # 起在 http://127.0.0.1:7900/ 并自动打开浏览器（正式数据在 data/app.db）
python server.py        # 同上（不开浏览器）
python server.py --db 某路径 --port 7930     # 换库/换端口
python server.py --selftest   # 自检（临时库：账号全链路 + 页面 + 边界，26 项）
```

## 目录

```
courselab/
  server.py        标准库 HTTP 服务 + 路由 + 会话 + 自检（零第三方依赖）
  app/             领域层：db（平台态库）/ auth（账号会话）/ courses（仓库现算）/ can（权限唯一源）
  web/             学生端页面：门户/登录/注册/课程工作区/项目页/我的（原生 JS，零构建）
  data/ logs/ backup/   运行期数据（不进 git）
  docs/PLAN.md     方案书（定位/里程碑/验收口径）
  docs/DESIGN.md   详细设计（多端/功能点 F1-F18/数据模型/API/部署）
  run.bat          启动脚本（纯 ASCII + CRLF）
```

说明：本目录与课设治理（showcase/g2/check_all）隔离；课程与项目数据现算自仓库
（`showcase/manifest.json` 是唯一出处），平台不维护第二份。
