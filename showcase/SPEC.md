# 展示层工程 —— 每个项目一个自包含 HTML 展示页（口径）

**用户点项（2026-10-03）**："每个项目都要有前端和展示"。本工程把它落成可验收的形式：
仓库里 33 个项目**每个一个自包含 HTML 展示页**（双击即看、零网络依赖），
仓库根 `showcase/index.html` 是总入口。**页面是提交物**（进仓库、进 git），
不是构建垃圾——生成器 + 新鲜度校验照 `traceability.csv` 的同一套做法。

## 一、页面规范（每条都有机器核对，`check.py` 执行）

1. **单文件自包含**：UTF-8 + `lang="zh-CN"` + 非空 `<title>`，以 `<!DOCTYPE html>` 开头；
   **零网络依赖**——`src=`/`href=`/`url()` 不得指向外部（协议或 `//` 开头）；
   全文出现 `http(s)://` 的唯一例外是 W3C 命名空间串（`www.w3.org`，它是标识符不是请求）。
2. **必备锚点**：`<body data-showcase="<项目 id>">`（与 `manifest.json` 对得上）、
   `id="facts"`（实测数字区）、`id="demo"`（展示/交互区）、`id="repro"`（怎么自己跑）、
   `id="lab"`（实时实验台分节，内含控制台挂载点 `id="lab-slot"`——缺它 lab.js 就升不成控制台）。
3. **生成物标记**：页脚必须含重生成命令字符串 `tools/showcase.py --write`。
4. **脚本规范**：不用 `innerHTML / outerHTML / document.write / insertAdjacentHTML`
   （数据可信与否不是例外理由）；每个内联 `<script>` 过 `node --check`
   （机器上没有 node 时记一条 skipped，不算红）。
5. **数据全部现算**：页面数据由各项目 `tools/showcase.py` 从**本仓库真实产物**现算嵌入；
   `--check` 重算比对，过期即红。
6. **交互 = 对真实产物的回放 / 切换 / 筛选**，不是第二套实现：JS 里不许重算业务结果，
   只负责把现算好的数据渲染出来。
7. **观感归用户**：好不好看、顺不顺手由你双击打开验收，我不代勾（与 B16 走查同一规矩）。
8. **统一设计 token（KB 主题，2026-10-03）**：配色/圆角/阴影/过渡取自 kb-ui 设计系统（slate 色板 +
   `#3b82f6` 主色、4/6/10px 圆角、两档纸感阴影、0.2s 过渡），同一份 CSS 块追加在**每个生成器样式常量末尾**
   （改主题只改这一块，再全部 `--write`）；总入口与实验台控制台（lab.js）同套 token；仍零外部依赖。
9. **内容口径**：展示面只放**课程交付物**内容——不出现"非课程的个人活动"（如讲座记录、实习经历的
   描述与框架，2026-10-03 用户口径）；官方课程名映射属台账事实，保留。

## 二、生成器与校验规范

- 生成器：`projects/<P>/tools/showcase.py`，两种模式——
  `--write` 现算并写出 `projects/<P>/web/showcase.html`；`--check` 重算比对（不写盘），退出码 0/1。
- 项目内测试：新鲜度、数据抽查（与现算源一致）、自包含 lint、负面对照。
- 仓库级：`showcase/check.py` 统一再验（结构 + 自包含 + node --check + 逐项目 `--check`
  子进程 + 总入口新鲜度与链接）；负面对照在 `showcase/tests/`。
  `showcase/lab.js` 也过 `node --check`（页内控制台的脚本，语法错就是整台控制台哑掉）；
  跑各项目 `--check` 的子进程**强制 `PYTHONUTF8=1`**——生成器自身 stdout 默认跟控制台走
  （本机 GBK），父进程按 utf-8 解，不强制会出现乱码 note、GBK 控制台上直接崩（2026-10-03 实测修）。
- 总入口：`showcase/index.html` 由 `python showcase/check.py --write-index` 从
  `manifest.json` 生成（已交付的给链接、待补的给状态签）；链接目标不存在即红。

## 六、交互组件（2026-10-03 升级，随生成物一起受新鲜度校验）

## 七、实时实验台（showcase/lab.py，2026-10-03）——让前端真正控制后端

用户反馈"前端相当于 PPT，缺少对真实后端的控制"后的补齐：展示页默认仍是**静态自包含**（双击即看），
另外提供一台**本地实验台**，页面接上它就从"录像"变成"控制台"：

- **启动**：双击仓库根 `lab.bat`（Windows 双击即用：起 7788 并自动打开总入口；`lab.bat no-open`
  只起服务，`lab.bat lan` 局域网模式，`lab.bat selftest` 复跑自检；**参数顺序无关**；正文纯 ASCII + CRLF，
  沿用全仓 .bat 规矩），或 `python showcase/lab.py`（纯标准库，只绑 127.0.0.1:7788；
  `--open` 才自动开浏览器——lab.bat 默认传）。之后从
  `http://127.0.0.1:7788/showcase/index.html` 打开任意页面，或双击本地页（实验台在跑即可）——
  每页正文尾部的**「实时实验台」正式分节**（`id="lab"`，与 facts/demo/repro 并列，顶部导航有跳链；
  2026-10-03 由角落浮窗升级而来）会**就地**变成控制台：启停服务、发原始请求、看实时日志；
  实验台没跑时该分节显示静态启动说明，页面其余部分完全不受影响。
- **重复启动 = 复用（2026-10-04 顺滑度）**：已有实验台在跑时再双击 lab.bat **不是错误**——
  复用它、按需再开页面、退出 0；带 `--lan` 的重复请求会提示"先把原实例 Ctrl+C 停掉再重跑"。
  只有"端口被别的程序占着"才维持报错 + 退出 1（错误语义不混）。
- **端口被占**：先连接探测再绑定——第二个实例会给出人话报错并退出 1（分辨"已有实验台在跑"还是
  "别的程序占着"，建议换端口），不依赖 bind 失败：Windows 的 `SO_REUSEADDR` 允许双绑同一端口，
  只看 bind 会静默起两个实验台（2026-10-03 实测踩到后改的）。
- **能做什么**：启动/停止 6 个**已注册的真实服务**（B11 netlab HTTP、B31 短链、B38 Redis 子集、
  B35 MQTT broker、B28 看板、dorm 原型），对运行中的服务**发任意原始请求**（文本框里 `\r \n \t \\ \xNN` 转义成字节；回复文本 + 字节并排显示），对全部 Python 项目**真跑 demo.py/测试套件**（B1/B2/B5/B6/B7/B9/B14
  走 `run.bat`），并**实时看**这些进程的 stdout/stderr。B8 要在 WSL 里跑，实验台不替它选环境（如实显示未接）。
- **长任务可中止（2026-10-04 操作补全）**：非服务项目补 `stop_run`「停止运行」动作（demo/测试/run.bat
  这类长任务出错了不用重启实验台）；Windows 下 `_stop` 改 `taskkill /F /T` 杀**整棵进程树**——
  只 `terminate()` 外壳的话，`cmd /c run.bat` 的子进程会活下来继续跑，页面显示"已停止"日志却还在长
  （受控探针实测复现过：外层死后 tick 仍持续增长）。SERVE 项目已有「停止服务」按钮，不重复给。
- **API**（页面 lab.js 与 lab.py 一一对应）：`/lab/api/ping|info|start|stop|run|log|sock|overview`。
  其中 `overview` 是总入口控制台专用：一次返回全部项目的动作清单 + 实时状态（只读）。
- **项目群控制台（总入口，2026-10-04 交付；用户 10-03 晚点"可交互、可投入使用的项目群"）**：`index.html` 的
  `body` 带 `data-lab-index="1"`，实验台在跑时每行项目**就地长出** 状态点（●运行/○未运行，
  3 秒轮询）/ 启动 / 停止 / 演示 / 测试 / 运行 / 日志（行内实时输出）按钮；顶部 `#hub-hint`
  横幅显示连接状态。实验台没跑时本页仍是原来的静态自包含页（零变化）。
- **局域网模式 `--lan`（lab.bat lan）**：静态页绑 `0.0.0.0` 供同网段浏览，启动时打印各网卡入口；
  **控制面永远不出本机**——`/lab/api/*`（含只读 overview）在服务端按来源判定，非回环一律 403
  （`_is_loopback` 认 127/8 与 `::1`、`::ffff:127.0.0.1`）；页面侧收到 403 会显示
  "控制仅限本机"提示并保持静态浏览可用。
- **友好路由**：`GET /` 302 到总入口；404 换成**指路页**（写明静态根=仓库根、总入口
  `/showcase/index.html` 可直接点）——2026-10-03 用户误敲 `/projects/showcase/index.html` 后补齐。
- **安全边界（写死）**：默认只绑回环（`--lan` 只放开静态）；只执行 `lab.py` 注册表里的**固定命令**

- **页面侧**：每页生成物里内嵌一段引导脚本（无花括号、f-string 安全；`file://` 时从 127.0.0.1:7788
  加载 `/showcase/lab.js`，加载失败则分节保持静态说明）；控制台界面全部 DOM API 构建（无 innerHTML），
  `lab.js`、每页内联脚本与总入口两段内联脚本都过 `node --check`（校验器执行）。
