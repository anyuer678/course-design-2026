# LinkBox —— 自托管工具站（短链 / 文本暂存）

**产品定位**：一个跑在自己电脑上的工具站——短链缩短、文本暂存（带过期）。
数据只在本机，浏览器可用、手机同局域网可访问。它是课程任务 B31（短链系统）
的产品化延续：**引擎复用、产品新建**——短链核心（base62 编码 / 校验 / 存储）
与协议层（netlab）直接从 B31/B11 桥接，本产品只做产品层。

## 运行

```
run.bat                    # 自测（11 项）+ 演示（不占常驻端口）
server.py --port 8018      # 启动产品服务（浏览器打开 http://127.0.0.1:8018/）
```

数据目录 `data/`（首次启动自动创建）：`shorturl.sqlite` 短链库（与 B31 同构）、
`stash.sqlite` 暂存库。两库分离：暂存是高频写/频繁过期的临时数据，
与短链的生命周期不同——备份策略也该不同。

## 功能（M1）

- **短链**：创建（自定义短码可选）/ 302 跳转 / 命中统计 / 最近列表
  ——与 B31 完全同源，URL 校验 13 条规则全保留
- **文本暂存**：`POST /api/stash`（content + ttl_hours）→ 得到 `/s/短码`
  查看页；到期惰性清除（访问时删除并返回 410）；可提前 DELETE
- **产品页**：响应式（手机同网段可用）、短链/暂存/统计三选项卡
- **HTTP API**：见下表

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/links | 创建短链 {url, alias?} |
| GET | /api/links | 最近列表 |
| GET | /l/<code> | 302 跳转 |
| GET | /api/links/<code> | 单条统计 |
| GET | /api/stats | 总览 |
| POST | /api/stash | 新建暂存 {content, ttl_hours?} |
| GET | /api/stash/<code> | 读暂存（过期 410） |
| DELETE | /api/stash/<code> | 提前删除 |
| GET | /s/<code> | 暂存查看页（内容 HTML 转义） |

状态码口径：400 内容不合法 / 404 不存在 / 410 已过期 / 413 超长 /
415 类型不对 / 503 容量满。

## 产品化相对 B31 的新增

- **文本暂存**：新表 + 新路由 + 惰性过期（B10 的"访问时清理"经验直接搬）
- **产品页**：单页双选项卡，业务判定全在服务端（前端只渲染）
- **数据目录**：`data/` 自动创建，短链库与暂存库分文件
- **XSS 防线**：暂存内容进 HTML 前一律 `html.escape`，并有回归测试
  （脚本注入必须显示为转义文本）

## 测试策略（11 项）

- 暂存闭环（创建→API 读回）、查看页 XSS 转义回归
- 过期：注入时钟推过有效期 → 410 + 惰性删除 + 计数核对
- 校验：空内容/超长/非字符串/非法 TTL/未知字段 → 全 400
- 删除：204 → 404
- 产品化回归：短链 create→redirect 302 与 Location 头不因产品化受损
- 产品首页可达；真套接字两条（暂存闭环 + 产品页）

## 已知局限

- 单进程；无账号体系（暂存是"凭链接查看"的匿名模型）；
- 惰性过期：不访问就不清理（库里可能留有过期行，只在被访问时删除）；
- 内容上限 100 KB；TTL 上限 1 年。

## 练习建议

1. 二维码：把 `/s/<code>` 查看页加一个"生成二维码"（手写 QR 编码或批准引库）。
2. 访问口令：给暂存加可选密码，查看页先验口令（hashlib.pbkdf2_hmac）。
3. 过期清扫线程：定时删过期行，并写一条"清扫了几行"的日志。
4. 用 B30 的一致性哈希把 stash 拆到两个"存储节点"——顺便理解为什么
   教学版先不做。
