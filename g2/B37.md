## 二、知识点速览（README 表格原文）

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
|---|---|---|
| 预测性维护的口径 | `window_label`（horizon=24、排除暂态窗） | 逐边界断言：f-t=24 正、25 负、t≥f 起排除、f+W+decay 后回归负样本 |
| 特征不泄漏未来 | `window_features` 只用窗口内读数 | 把某窗口之后的所有读数改掉，该窗口特征**逐位不变**（且更晚的窗口确实变了） |
| 概率分数与阈值 | 手写逻辑回归（sigmoid + 交叉熵） | 解析梯度 vs 数值梯度（实测 2.8e-11）；GD vs Newton 最大权差 1.9e-3（L2 下的唯一最优） |
| 复用不抄第二份 | `ml.tree.DecisionTree` / `ml.data` | `isinstance` 断言 + 跨项目路径存在性断言；模型改动测试特征后权重分毫不动 |
| 误报/漏报权衡 | `sweep` / `roc_points` / `auc` | 阈值降 => 召回与报警数单调不降（断言）；打乱标签 AUC 跌回随机（10 种子实测 [0.33, 0.56]） |

## 三、独立修改任务（README 练习建议原文；做完跑 `run.bat` 全绿）

1. （练习建议 1）把 `horizon` 从 24 改成 6 与 48 各跑一遍：提前量分布与召回怎么变？说清"要提前多久" 是业务给的，不是模型选的。
2. （练习建议 2）给随机切分臂换 3 个种子、给按设备切分换测试设备对（如 (4,5)），观察 AUC 波动—— 体会"单一切分的偶然性"（B23 练习第 1 条同款）。
3. （练习建议 3）把 `spike_delta` 调到 10（尖峰不再越过 100°C），固定阈值基线的误报解剖会怎么变？ 解释"阈值选在哪"和"数据里有什么"是同一个问题的两面。
4. （练习建议 4）给树加一个特征"距上次标定的步数"（或把 `temp_mean` 换成"相对本设备基线的偏差"）， 重跑按设备切分——想想为什么**去基线化**的特征才可能跨设备泛化。

### 延伸坑单（README 踩坑原文，任选一条复现）

- **"能整包复用"是错觉，复用的边界是实测出来的**：B35 `SensorSimulator` 480 步
- **仿真里"加在哪一层"会被量出来**：第一版把尖峰 `temp += delta` 加在**游走状态**上，
- **无惩罚 logistic 的 MLE 在可分开方向上发散**：第一版没加 L2，GD 与 Newton 的权重
- **logdiff 要连补位空格一起规范化**：耗时列 `{ms:>10.1f}` 在 766 与 1040 两种量级下
- **GBK 控制台扫净（B4 同款教训复发）**：一堆数学记号（蕴含/等价/偏导/转置/上标等）让 `python demo.py`
