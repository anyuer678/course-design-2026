## 二、知识点速览（README 表格原文）

| 知识点 | 代码 | 正确性靠什么 | 怎么验 |
|---|---|---|---|
| 分治递推 + 合并计数 | `divide.merge_sort_count` | 逆序对三分解；合并时右块先出则贡献 `mid-i` 对 | 值域 {0,1,2} 长度 ≤5 全穷举；500 组随机对暴力；测试里再加一棵独立写的树状数组 |
| 归并排序的稳定性约定 | 同上 `a[i] <= a[j]` | 相等元素不构成逆序对 | `[7,7,7,7] → 0`；降序数组恰好 `n(n-1)/2` |
| DP 状态与转移 | `dp.knapsack_table` | 对 `(i, w)` 归纳：`f[i][w]=max(f[i-1][w], f[i-1][w-wt]+v)` | 400~500 组随机与子集枚举比价值、比方案可行性 |
| 空间压缩与循环方向 | `dp.knapsack_rolling` | 倒序保证 `f[w-wt]` 仍是"上一件物品之前"的值 | 与全表逐组相等；正序版单独测出"同一件被装两次" |
| 方案还原 | `dp.knapsack` 的回溯段 | `f[i][w] != f[i-1][w]` <=> 第 i 件被选（价值非负） | 断言还原集合重量 ≤ 容量、价值 == 最优值 |
| 贪心 + 交换论证 | `greedy.schedule` | 用结束最早的 g 替换最优解的第一个，不损害后续 | 端点不超过 5、区间数 ≤3 的**全部 575 组**集合穷举；600 组随机 |

## 三、独立修改任务（README 练习建议原文；做完跑 `run.bat` 全绿）

1. （练习建议 1）给背包加 W 上限保护与大 W 退化路径（值域缩放或 meet-in-the-middle n≤40）， 说明它什么时候开始给出**近似**答案。
2. （练习建议 2）把带权区间调度做出来（DP + 二分找上一个不冲突区间），并与"最大数量"版本比较反例。
3. （练习建议 3）给 N 皇后加对称性剪枝（首行只搜一半，再乘 2），或改成迭代加深； 用 `experiments.py` 同一档规模比倍率，说明为什么量级仍然没变。
4. （练习建议 4）复用 B2 的 `huffman.hpp` 做一次真实文件压缩，统计 WPL 和实际字节数—— 这题要求的是"别在 Python 里再写一遍堆"。
5. （练习建议 5）给 Dijkstra 加 A*，启发式分别用曼哈顿距离和欧几里得距离， 说明**容许性**（不高估剩余代价）为什么是"结果仍最优"的前提， 以及欧几里得版为什么必须小心浮点比较。

## 四、失败复现任务（先写下「我预言哪条会红、为什么」，再动手）

### 延伸坑单（README 踩坑原文，任选一条复现）

- **三种图实现各用各的"边方向"约定**（真 bug）：Dijkstra 与 Floyd 把边表当无向（各自补一条反向边），

- **计时把输入生成也算进去了**：`bench.growth(fn, sizes)` 里 fn 自己造数据，测的是"生成 + 算法"。
