## 二、知识点速览（README 表格原文）

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
|---|---|---|
| Makefile 解析（目标/前置/recipe/`.PHONY`） | `Makefile.load` | 逐字段断言；重复目标、recipe 出现在目标之前都要报错 |
| 依赖图与拓扑序 | `Makefile.order` | 人工推的偏序逐条断言（`a` 在 `b` 前、`b` 在 `c` 前、`all` 最后） |
| 环检测 | 同上 | `a·b` 报错信息里必须出现 `a -> b -> a` 这条环 |
| 增量构建 | `needs_build` / `mtime` | 目标比前置新 → 不重建；`utime` 把前置调新 → 必须重建 |
| 失败传播 | `Builder.build` | 上游 `exit 7` → 返回码 1、**下游目标不执行**（断言产物不存在） |

> 出处：踩坑 1（相对路径必须相对 Makefile 目录）。对不上预言本身就是收获。

### 延伸坑单（README 踩坑原文，任选一条复现）

- **相对路径必须相对 Makefile 目录**，不是进程 cwd。第一版按 cwd 解析：在临时目录里跑测试时
- **失败传播是"流程"，不是"崩溃"**：`build()` 要返回非 0 并跳过下游，而不是把异常抛给调用方；
- **`classmethod` 里写了 `self.PHONY_PREFIX`**：构造函数里能跑通、类方法里当场 `NameError`。
- **我在这份 `run.bat` 里又踩了一次仓库自己记过的坑**：`echo ... clean -> full -> ...` 里的 `->`
- **原子替换要带断言**：我两次用脚本改测试里的 recipe，转义在 heredoc 里被吃掉，
