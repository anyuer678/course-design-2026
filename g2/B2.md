## 一、口述提纲（不看代码讲得出）

1. moves() 与 hops() 各计的是什么动作？头插 300 次为什么是 44850 步（n(n-1)/2）？
2. 循环队列用 size 记账区分空/满的取舍？改成"留一个空位"要动哪些断言？
3. BST 删除三情形（叶/单子/双子后继顶替）——以及"升序 31 个高 31 vs 折半插入高 5"说明什么？
4. 线性建堆为什么 O(n)：494 次比较 vs 逐个插入 1538 次要靠什么数据形状才逼得出来？

## 二、知识点速览（README 表格原文）

| 课程知识点 | 代码 | 验证方式 |
|---|---|---|
|---|---|---|
| 顺序表的"搬元素"代价 | `SeqList::insert/erase` + `moves()` | 小样例**手算**到每一步（3 个元素头插 = 3 步）；300 次头插实测 44850 步（n(n-1)/2） |
| 链表的"跳指针"代价 | `LinkedList::find/at` + `hops()` | 手算（找第 3 个 = 跳 2 步、比较 3 次）；同题对照：头插只改链 300 次 |
| 栈的应用 | `brackets_match` / `infix_to_postfix` / `eval_postfix` | 括号 8 例手算；`3*(4+5)-6` → 后缀 → 21；括号不配对/非法字符/除零**必须抛错** |
| 循环队列的空/满 | `ArrayQueue`（size 记账） | 容量 4 的 head/tail 全手推（满时 head==tail==0 的"相遇"）；随机操作 vs `std::queue` |
| BST 删除三情形 | `BST::erase` | 叶/单子/双子（后继顶替）逐情形手推中序；随机操作 vs `std::set` |

## 三、独立修改任务（README 练习建议原文；做完跑 `run.bat` 全绿）

1. （练习建议 1）给 `SeqList` 加"按值删除全部"并说明它各要搬多少步；给链表同题，对比两个计数器的差距。
2. （练习建议 2）把循环队列改成"留一个空位"区分空/满（不用 size 记账），写出被改红的测试。
3. （练习建议 3）给 BST 加 `successor/predecessor`，用它们重写 `erase` 的双子分支并跑全量对拍。
4. （练习建议 4）给线性探测加"墓碑数量超过一半就重散列"，比较重散列前后的总探测数；
5. （练习建议 5）把 `Heap` 接成 `top-k`（维护 k 大小的小顶堆扫一遍），说清它和全排序的复杂度差在哪。

## 四、失败复现任务（先写下「我预言哪条会红、为什么」，再动手）

故意把某条计数的期望值写错一位（例如"删头部 5 个、搬 4 步"写成 3 步），跑测试——它抓不抓？这条练习的教训是"失败先怀疑自己的期望值"。

> 出处：踩坑 2（手算计数也会错）。对不上预言本身就是收获。

### 延伸坑单（README 踩坑原文，任选一条复现）

- **`in_order` 是"追加"语义**：我的测试复用一个 `SeqList` 收遍历结果，忘了清空——
- **手算计数也会错**：删头部 5 个元素的一批"搬动"我手数成 3 步，实际 4 步——
- **中缀转后缀按位读会拆散多位数**：`10+2` 第一版产出 `1 0 2 +`（字面量被拆成两个词），
- **空桶查找不比较键**：`probes()` 对空桶不加计数是我实现的口径（看了 0 个键）——
- **随机数据的堆对拍看不出建堆优势**：随机序列下逐个插入平均只上浮 ~1 层，
