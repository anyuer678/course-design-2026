## 一、口述提纲（不看代码讲得出）

1. HTTP 子集的边界语义：chunked 拒绝、CL 冲突、裸 LF 立刻 400——为什么这些由解析器统一收口？
2. 协议层的非法输入必须是 400：什么情况会让它冒成 500、为什么那是协议实现错误？
3. `Connection: close` 的承诺要在行为上兑现：发完承诺的响应 → SHUT_WR → 读干净 → EOF 回收。
4. GBN 的累积确认 vs SR 的缓存：同一丢包轨迹下有效载荷比不同在哪？
