### SensorHub /api/series 三层根因逐层剥（提交 cf35c00）

| 层 | 根因 | 修复 | 效果 |
|---|---|---|---|
| 1 | 全量载荷（长跑库 160KB/次） | limit 参数（默认 500/上限 5000/越界 400） | 160KB→8.2KB |
| 2 | SQL 全量取回再切尾 | limit 下推 B35 recorder（主键索引反向扫描；缺省 None 原语义不变） | 裸 SQL 8.3ms→0.5ms |
| 3 | _call 吃 hub 线程 50ms 轮询量子 | hub 主循环改队列阻塞等待（即到即办，节拍由 timeout 兜底） | +75~125ms 常数→消失 |

实测：series p50 152→**16.6ms**（-89%）、p95 650→28ms；status 78→30ms；chart 191→32ms。
验证：sensorhub 19 项 + B35 32 项双绿。教训：单线程 select 架构下，任何走
跨线程队列的接口都要审视"轮询量子"级别的常数延迟。

## 二、UX 走查发现（浏览器 agent 实访 6 页）

### Studio 门户 :8017
1. 登录后顶栏同时挂着登录表单和"已登录"状态（冗余；应隐藏表单）
2. 操作零反馈：登出后头部纹丝不动、错口令无提示、按钮无 loading 态
3. 侧栏高亮错位（点"账户"高亮仍停在"产品矩阵"）；直开 /#account 不定位

### LinkBox :8018
1. hash 深链接失效：直开 /#stash、/#files 不切换视图（应响应初始 hash 与 hashchange）
- 总评：三页中视觉与交互最完善

### CacheKV :8021
1. Console 1 条 ERR_ABORTED（对 / 的重复请求被中止）
2. "注入演示数据"入口重复（顶栏+侧栏运维区）
3. 键名过滤框在总览/命令行页常驻，与当前内容脱节

### CourseLab :8024
1. 首页搜索空态卡只占栅格 1/3（应 grid-column: 1/-1 跨满行）
2. 相邻批次色点撞色（批次 5/6 同绿，hsl 映射循环）
3. 卡片简介在数据层被截断停在逗号处，读感突兀

### DataScope :8020
1. 示例数据载入三处重复入口（顶栏/侧栏快捷/卡内），建议收敛 ≤2
（第 2-4 步未走完——浏览器被并行 agent 抢占，串行补走）

### SensorHub :8022 —— 未走查（同上原因）

### 走查方法论教训
- browser_use 两个 agent 不能并行（共用一个浏览器互抢标签页），必须串行；
- /@vite/client 的 ERR_ABORTED 是 Trae 编辑器注入（全仓 grep 无此引用），
  非页面缺陷——两条 agent 结论矛盾时必须亲自 grep 裁决。
